# Mizar 1.1.0

Mizar 1.1 增加应用内更新，并改善安装向导、BP 和播出昵称。

**[下载 Windows 安装包](https://github.com/Starfie1d1272/Mizar/releases/download/v1.1.0/Mizar-v1.1.0-Windows-x64-Setup.exe)** · [便携包](https://github.com/Starfie1d1272/Mizar/releases/download/v1.1.0/Mizar-v1.1.0-Windows-x64.zip) · [安装与使用手册](../guide/quick-start.md)

## 本次变化

- 增加可信的应用内更新：验证正式版本来源与安装包，安全退出后安装，并提供取消、失败和中断后的恢复工具。制作、节目接管、OBS 输出和打开的编辑工具会阻止安装。
- 统一中文安装向导与品牌素材，保留用户级安装及用户数据路径。
- 改善 BP 战队身份与禁选层级，统一“先禁图方”说明，裁去已确认的播出昵称队名前缀。
- 收敛重复 CI 职责，修复浏览器受控时钟竞争，强化资格与晋级的精确源码、main 签发工作流和原始资产身份核验。

## 安装与更新

1.0.0 没有更新客户端，首次升级到 1.1 须备份资料、正常退出 Mizar，再运行安装包。安装版资料保存在 `%LOCALAPPDATA%/Mizar`，便携版资料在包目录的 `state/`。

1.1 的后台检查默认关闭，可在「高级设置 → 应用更新」主动检查。来源或安装包无法验证时保留正式下载入口。便携版继续手动下载，不自动迁移资料。

更新失败或中断后，按应用提示使用恢复目录中的 `Restore-Mizar.cmd`；保留备份供重试。自定义用户数据目录位于安装目录内时，请手动备份和升级。跨主版本不自动安装。

## 发行证据与限制

正式 Release 随附精确源码身份、原始 ZIP 和安装器摘要、资格验证记录及更新清单来源证明。自动化与 Windows 实机验收结果分别记录，具体覆盖范围以当次发行证据为准。

安装包尚无 Windows 发布者代码签名；GitHub 构建来源证明与 SHA-256 用于验证来源和字节身份，不代替 Windows 发布者签名。

[反馈问题](https://github.com/Starfie1d1272/Mizar/issues)时请注明版本、安装或便携形态、Windows 版本与复现步骤，勿发送包含凭据的日志或资料。

# Mizar 1.0

> 让校园赛事，也有职业赛场的转播呈现。

Mizar 是面向校园与社区 CS2 赛事的开源制播系统。它将节目编排、制播工作台、HUD、雷达与赛事资料整合在本机，让小型制作团队也能完成从赛前到赛后的转播。

## 从准备比赛到正式播出

- **连贯的节目流程**：赛前等待、BP、对阵开场、局内画面、半场数据、单图结果、图间与整场结果随比赛推进，也可随时人工接管。
- **围绕比赛的工作台**：同屏查看 CS2、大雷达、比赛资料、制作提示和 OBS 状态，常用场景与观战操作集中在手边。
- **五套 HUD 风格**：默认 Mizar Pulse 提供完整节目包装，另有 EWC、IEM、Perfect World、ESL 风格 HUD。编辑器支持实景预览、组件配置、布局调整与预设分享。
- **本地赛事与平台连接**：本机保存赛事、队伍、名单和 BP；连接 RivalHub 后复用网站比赛资料，并向观众页提供局内状态与雷达。
- **现场恢复与诊断**：连接恢复、配置备份、数据源停止与重新接管、未保存 BP 草稿保护，以及中文故障提示与诊断导出。

## 安装与升级

在 [GitHub Releases](https://github.com/Starfie1d1272/Mizar/releases) 选择版本，下载名称以 `-Setup.exe` 结尾的 Windows x64 安装包，按中文向导安装。首次使用需准备 CS2、OBS 和 Microsoft Edge WebView2。Node 随包提供。

安装版升级前正常退出 Mizar，再运行新版安装包。比赛与配置保存在 `%LOCALAPPDATA%/Mizar`，卸载时保留。便携版完整解压后运行 `Mizar.exe`，数据位于包目录的 `state/`；从便携版转为安装版时，先备份原目录，再按[操作手册](../guide/quick-start.md)核对资料与配置。

1.0 安装包采用未签名分发，Windows 可能显示发布者未知或安全提示。请核对下载来源，并使用 Release 附带的 SHA-256 校验文件确认安装包完整性。后续版本通过下载新版安装包升级。

## 开播前的准备

1. 创建或选择比赛，核对名单、地图与 BP。
2. 在准备中心完成 CS2、GSI 与 OBS 配置检查。
3. 启动游戏并打开工作台，连接观战地址，确认实际比赛数据。
4. 在 OBS 检查游戏画面与 HUD，选择音频设备并录制试听，再开始推流。

## 使用范围

Mizar 1.0 支持 Windows x64 的 CS2 观战与 OBS 制作。节目编排负责场景推进，观察视角和推流启停由制作人员操作。半场与结果页使用单图统计，整场结果的选手表展示最后一图。

C4 伤害预测按当前位置与站立姿态估算，供观察参考；实际伤害以游戏结果为准。OBS 缩略图用于定期确认画面，开播状态用于核对直播连接，观众端音画需结合实际直播间检查。完整说明见[数据源能力](../guide/data-source-capabilities.md)。

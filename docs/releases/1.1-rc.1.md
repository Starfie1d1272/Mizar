# Mizar 1.1.0-rc.1

这是 1.1.0 的候选版，供试用与发布前验证；正式 1.1.0 尚未发布。

**[下载 Windows 安装包](https://github.com/Starfie1d1272/Mizar/releases/download/v1.1.0-rc.1/Mizar-v1.1.0-rc.1-Windows-x64-Setup.exe)** · [便携包](https://github.com/Starfie1d1272/Mizar/releases/download/v1.1.0-rc.1/Mizar-v1.1.0-rc.1-Windows-x64.zip) · [安装与使用手册](../guide/quick-start.md)

## 本次变化

- 增加可信的应用内更新流程：校验正式版本来源与安装包，安全退出后安装，并提供取消、失败及中断后的恢复机制。比赛、节目和 OBS 状态继续阻止不安全的安装。
- 统一中文安装向导与品牌素材，保留用户级安装、重装、卸载及用户数据路径。
- 改善 BP 战队身份与禁选层级，统一“先禁图方”说明，并裁去已确认的播出昵称队名前缀。
- 收敛重复 CI 职责，强化未知资格文件的完整验证，修复浏览器受控时钟竞争。
- 统一 main 工作流、构建源码和来源证明身份；晋级继续消费原始合格资产。正式 Cargo full LTO 与 NSIS solid LZMA 参数保持不变。

## 安装与更新

从 1.0.0 升级须先备份资料、正常退出 Mizar，再运行本候选安装包。1.0.0 没有本次新增的更新客户端，不能通过应用内更新接收本候选。

本 RC 不生成 Stable 更新清单，不进入国内 Stable 镜像或后台自动更新。应用内更新仅接受通过验证的正式 Stable；便携版通过手动下载管理程序目录，不自动迁移 `state/`。

安装版资料位于 `%LOCALAPPDATA%/Mizar`；便携版资料位于包目录的 `state/`。请保留旧版安装包和资料备份，正式制作前核对自己的安装路径与恢复操作。

## 验证范围与待验收项

本候选的源码、编译版本、原始 ZIP/安装器摘要及资格验证记录随 Release 资产提供。自动化覆盖完整 CI、原生 Windows 安装/重装/卸载、桌面启动与失败清理，以及真实文件系统上的可控安装器取消、失败和中断恢复。

本次尚未进行真实 CS2/OBS 制播、125%/150% DPI、实际登录触发恢复或旧 Stable 到新版的完整实机升级验收；可控安装器桩不代替真实跨版本 NSIS 更新恢复。RC 的发布不表示这些正式发行条件已满足，请勿仅依据自动化结果将其用于未经核对的正式赛事。

安装包尚无 Windows 发布者代码签名；GitHub 构建来源证明与 SHA-256 用于核对来源和字节身份，不代替 Windows 发布者签名。

[反馈问题](https://github.com/Starfie1d1272/Mizar/issues)时请注明 `1.1.0-rc.1`、安装/便携形态、Windows 版本和复现步骤。不要发送包含凭据的日志或资料。

# 诊断回传容量测量

这是 2026-10-17 在 Linux 开发环境运行真实 SessionJournal / DiagnosticDelivery 代码的合成负载。没有用户私有材料，没有对外上传。基础为 PR #391 的 `b4546cae501cb4689691ec53e9b24fd4fba32fe0`；脚本和原始数字随本目录提交。随机请求 ID、压缩栈路径会使再次运行的字节数略有不同。

复现：`pnpm --filter @mizar/companion exec tsx test/support/measure-diagnostic-delivery.ts`。脚本明确生成加速模型时间，经过异步记录、真实落盘、分批 gzip、进程对象关闭/重新初始化、重试与确认，解开每份批次检查错误 cause。远端是内存服务，不能当作真实 Worker/D1/R2 并发吞吐、CPU、额度或 Windows/CS2/OBS 实机证据。

## 负载与覆盖

两小时模型每两秒四次本产品控制读取，每次有 incoming 与 response 两条日志；每十五秒一个运行时性能窗口及两页浏览器性能窗口；每分钟一个业务操作的 received/begin/result；每十分钟一次带 ENOSPC 原始 cause 的失败。共 30,612 条生成事件（约 15,306 条/小时），不按空安装数量估算。默认十五秒窗口节奏来自当前实现；请求速率、载荷字段、错误频度和两个文档是显式假设，不是现场测得使用分布。同一分钟合成操作的 received/begin/result 共用一个 operationId；这是容量输入，不是生产任务集成或正确关联合同的测试。

此模型尚未包含新任务字段、待实现的输入停顿前后窗口及受管 CS2 控制台。旧支持包和跨比赛 OBS 日志不在分母中，也不能替代新版每场流量。最终上线预算需要集成后三种任务真实操作集再测；当前测量只验证已有队列和说明容量敏感项。

## 本轮结果

精确值见 [result.json](result.json)。本节 **MB 均为十进制 1,000,000 字节**。两小时展开批次 14,444,905 字节（14.445 MB），gzip 784,798 字节（0.785 MB），120 个批次，12 条完整错误链验证通过；源日志与发送正文均无缺失。每小时约 0.392 MB 压缩；每日三场两小时约 2.354 MB/安装。

这些是测量模型的线性预测，不是云端实测。索引列仅计算当前 batch.index 的 JSON 字节，尚无 SQL 行、检索字段及索引开销；不能当作 D1 实际数据库大小。每批 1 KiB 是另一预算包络而非最小值，100 安装九十天约 3,317.760 MB。D1 Free 单库 500 MB，故不能默认把所有逐批索引保留九十天；应分开设计七天正文定位信息与九十天场次/问题检索索引，并实测真实 SQLite 大小及查询写入量。

另测 10 / 30 / 100 个独立本地管线同时执行一分钟正常模型，分别生成 2,560 / 7,680 / 25,600 条事件；所有错误链经真实磁盘恢复和确认后验证。它们证明本地管线并发执行，不证明云平台请求吞吐。

故障峰值按每秒一百条错误持续一分钟，生成 6,000 条，各自保留原始 cause、操作身份、重试序号及状态；展开 7,825,808 字节，gzip 248,985 字节（0.248985 MB），21 批。重启后排空用了 23 次 tick，包括重启产生的新记录，并非已经历相同分钟数。触发一次内存预算回压，全部从持久源日志补回，6,000 条错误逐条验证；报告中的 memory_budget_recoverable_from_local_journal 计数是发生过回压，不能解释为六千条错误丢失，也不能删去该告警。此负载只持续一分钟，不能据此承诺无限刷屏保留。

## 已发现的限制和下一步

当前本地最多 256 批，在此模型只覆盖约 4.27 小时离线积压，早于 32 MiB 字节上限；需要改善批次数预算或合批策略。当前每分钟仅确认一批，21 批故障峰值会拖长清空；需要有界异步加速排空并保持取消、退避和实时采集不阻塞。

按当前一分钟一对象，100 安装每天六小时、每月三十天约 108 万 PUT，超过 R2 Standard 免费层每月一百万 Class A，还未计其他账户使用；七天保留只降低存储量，不能减少写入次数。后续分批策略须兼顾快速分诊、问题标记立即提交、请求预算与压缩收益，而非通过每日小上限让正常用户缺证据。共享账户剩余额度无法由应用自身统计证明为全账户硬限制。

额度依据：[R2 定价](https://developers.cloudflare.com/r2/pricing/)、[D1 限制](https://developers.cloudflare.com/d1/platform/limits/)、[D1 定价](https://developers.cloudflare.com/d1/platform/pricing/)。这些模型不构成平台永不收费承诺，不执行账户升级、部署、绑定或七天永久清理。

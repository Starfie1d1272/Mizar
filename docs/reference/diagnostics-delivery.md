# 技术诊断回传

本入口负责技术诊断的回传同意、可靠待传队列及云端容量边界；本机证据主体、脱敏与人工导出仍由[架构中的诊断规则](architecture.md)负责。自动回传不修复或证明任何现场 HUD 根因。

## 当前实现阶段

第一批仅提供 Companion 本地待传队列基础，尚未接入正常用户界面、生产启动或云接收服务。默认没有端点、默认不同意、不发网络请求；不部署、不创建凭据、不改权限。后续任务入口、异常输入窗口与受管控制台读取单独验收，不能因基础队列测试通过就宣称全部采集完成。

## 同意与撤回

使用者必须明确获知上传的是技术诊断而非匿名数据，可能包含机器、路径、赛事和选手标识；密码、令牌、Cookie、推流密钥等凭据精确脱敏，保留排障所需上下文。不得补传同意前的记录，不上传音视频或私人聊天。未知聊天与队内/私聊不能默认上传。当前待传副本排除聊天字段和聊天阶段；本机人工导出与云副本范围不同，不得据此声称原日志完整上云。

关闭先使内存同意失效并中止进行中的请求，立即写入独立且同步的撤回标记，再按串行事务持久化撤回意图并清除待传正文。状态文件写入失败时保留标记，重启先强制关闭旧同意并恢复删除意图；不能仅因内存已关闭就报告落盘成功。并发开关按请求顺序处理，旧启用请求不能擦除后续撤回标记。网络已经送出的字节不能收回；云端删除只有在收到相同安装身份的完整删除确认后才算完成。断网时保留删除意图，界面应显示待同步，不能显示已经删除。再次同意使用新的随机安装身份；未同步撤回最多八份，达到上限时先同步，不能无限积累身份。

## 本地可靠性

队列只观察既有 SessionJournal 持久提交。每个允许采集的进程会话保存同意起点和已入队序号；重启只从固定的会话日志段补入该范围，不读取任意私人文件。日志已轮转、过期、损坏、超载或过大事件分别标记缺口，不能把采集器零丢帧或上传成功当成全链完整。

gzip 批次先写入独立文件并同步；队列引用和源游标写入同一原子状态文件后才允许上传。重启删除未被该状态引用的孤立批次。网络失败、错误身份/摘要的确认、服务端拒收不移除批次；确认丢失后以相同 SHA-256 批次身份重试，服务端必须幂等。收到确认后先原子更新队列；提交失败必须恢复内存队列供相同批次重试，再删除正文，删除失败留下的孤立文件可在初始化清理。

单批展开不超过 512 KiB、压缩不超过 128 KiB、最多 512 个事件；不合尺寸先拆小批，单条仍超限时标记云副本缺失，原始本机日志保持原有保留规则。内存待处理不超过 2 MiB，持久待传正文不超过 32 MiB；队列满时不静默淘汰未确认批次，而是停止新增副本并显示积压，源日志仍按其既有预算轮转。维护读取器也限制实际解压大小，不能信任上传端声明。

请求仅向配置的 HTTPS 固定源发送，禁止重定向；仅测试允许回环 HTTP。使用每安装随机登记身份与随机登记证明，不在产品中嵌入共享服务密钥。登记和上传的令牌只保存在受控队列状态中，不能纳入诊断正文。退避由 30 秒增长到最多约六小时并加抖动；关闭同意不等待退避。

## 云端存储与费用边界

当前基础队列没有云端端点，不执行部署。经使用者确认，后续云端采用私有 R2 保存客户端异步 gzip 压缩正文、D1 保存可检索索引；正文保留七天，索引九十天暂为可配置候选。此前 D1 保存正文、十四天正文保留和全局每日 12 MiB / 256 批的候选均不再作为实现目标。

正常使用预算须依据新版实际事件量和压缩量实测，再给单场、每日多场和多用户容量预测。旧支持包和跨比赛 OBS 日志只能说明既有材料体积，不能当作新版每场上传量。预算保护与异常滥用保护分别设计；不能通过删掉失败、重试、原始 cause、状态转移或性能停顿上下文来缩小流量。

R2 免费额度是账户共享资源，应用限流、费用告警和应用自身容量统计不构成全账户零元硬封顶；不承诺其他应用使用量可被实时感知。不升级账户或购买付费能力，接近获批预算时暂停接收并明确显示本机积压与未上传范围。真实绑定、密钥、部署和七天正文永久清理需父会话确认；不修改或删除其他桶及生产数据。


## 验证职责

队列负责测试默认关闭、同意起点、脱敏、断网、进程重启补入、丢失确认与幂等、假确认、中途撤回、离线删除同步、不安全文件与解压上限；另覆盖并发同意开关、批次 fsync / 状态提交中撤回、回执提交失败回滚、撤回提交失败重启、完成游标回收和有界响应读取。真实 Worker/R2/D1 配额、Windows CS2 控制台、OBS/CEF 和实际网络的证据独立记录；合成服务测试不能冒充这些实机结果。

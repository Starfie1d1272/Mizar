# 应用内更新

更新属于分发能力，由 Companion 验证版本和下载，桌面宿主负责执行用户发起的升级与正常退出。既有比赛、节目、OBS 和用户资料继续由原模块持有。

## 可信元数据

Stable 使用 `update-manifest.json`，结构标识为 `mizar.update.v1`，包含仓库、正式版本、源码 SHA、中文更新说明、兼容的旧版范围及 Windows x64 NSIS 安装包的名称、字节数、SHA-256 和内容摘要。资格构建在便携包与安装包通过验证后从原始分发清单生成，签发同一 GitHub 构建来源证明，并保存原始 `update-provenance.json` 验证包；晋级上传原清单、证明和原安装包，不重新打包。发布配置中的版本必须与应用版本一致。

检查优先读取南大 Box 的 `Updates/latest.json`。该 `mizar.update-index.v1` 信封只包含原清单的 Base64 字节及验证它所需的原始 Sigstore 证明，不另同步整套发布证据。客户端必须验证证书、透明日志及清单摘要，签发者必须是本仓库 main 上的 Release Qualification，清单源码必须等于签署的构建源码。Box 未同步、不可用或验证失败时回退到内置仓库的 GitHub HTTPS 接口，排除草稿和预发布版本，按 SemVer 判断新旧，再核对证明、正式标签和资产身份。客户端保留的最高版本还用于排除落后的镜像。

Sigstore 的内置 TUF 根负责信任根更新、轮换与吊销，不接受下载源指定的公钥、证书或信任根；验证需要可用的 Sigstore 信任元数据网络。两个分发源均不可验证、元数据缺失或兼容范围不匹配时仅保留正式 Release 页面，不能下载安装。

客户端保留已验证版本和摘要，拒绝回退及同版本换包。此记录只在完整来源验证后更新；网络检查失败不覆盖已验证信息。更新说明作为文本显示，不执行 HTML、脚本或清单提供的链接。

## 检查与下载

用户可主动检查。后台检查默认关闭，开启后最多每日一次，失败同样计入频率限制；退出制作中心不会弹窗、抢焦点或安装。检查、下载和失败阶段写入有界本机日志，日志只记录阶段、版本和错误代码，不记录凭据或临时下载地址。

下载优先核对南大云盘 Stable 的精确文件名与大小，失败回退 GitHub 原资产。两者均使用已认证清单的大小与 SHA-256 验证全部字节；云盘清单和 `.sha256` 不作为发布者认证。请求和重定向限定 HTTPS 允许地址，响应、磁盘写入和时长均有上限。每次下载使用程序资源目录外的独立暂存目录；取消、失败及重试清理不完整文件。下载完成可稍后安装，重启后重新验证元数据和完整文件。

客户端使用专用的公开资料库只读 Token，查询时核对 Mizar 资料库和 `r` 权限；只允许列目录和获取下载链接。Token 不承担签名职责，不进入日志，不随下载重定向发送，不能复用发布工作流的读写凭据。Token 失效时回退 GitHub。

`Stable/` 始终只保留最新正式 Setup.exe，既有公开分享链接不变；`Archive/` 继续只归档历史正式安装包；`Updates/` 独立保存机器读取资料。Box Sync 先上传并完整校验安装包、完成历史归档，最后以完整文件替换 `Updates/latest.json` 并回读核对；前序任一步失败保留旧清单。清单与必要证明放在同一信封，避免分别替换出现混配。GitHub 保留完整原发布资产、证明和回退入口。

## 安装与恢复

安装版通过既有 `installed.flag` 识别。便携版只显示更新说明及正式下载入口，不启动 Setup，不迁移 `state/`。自动安装只支持同一兼容范围，跨主版本或回退通过人工备份、迁移及验收处理。

更新页默认展示版本与更新日志。「一键更新」是用户对下载及安装的明确授权，验证通过后自动衔接安全退出、静默安装和重新打开，不再要求第二次确认或备份勾选。选择「稍后」、取消、验证失败或进入制作会取消本次安装意图；保留的下载不会因后台轮询或退出制作自行安装。Live、隐藏但仍在制作、节目手动接管或切换中、OBS 推流或录制中、无法核对播出状态，以及打开的编辑工具均阻止安装；下载可以保留。先保存资料、关闭编辑工具并结束制作，再升级。宿主重新核对条件，禁止浏览器提交路径、安装命令或任意下载地址；准备升级期间禁止新的制作与场景接管。

退出复用正常制作收尾、游戏恢复、持久化写盘和本地服务关闭。任一收尾失败取消安装，原程序保持可用。安装工具在资源目录外独立运行，确认宿主和服务退出、重新核验安装包后，备份旧程序，再以原目录静默调用 NSIS；受控升级固定原安装目录，不覆盖运行中的文件。新程序完整载荷验证通过后恢复用户已有桌面快捷方式；原来没有快捷方式时不新增。随后提交升级并自动重新打开。

安装工具记录恢复日志并注册当前用户登录后的恢复入口。取消、错误或新版完整性检查失败时恢复备份的程序、卸载登记和快捷方式；中断后下次登录完成恢复。恢复失败保留备份和可直接运行的恢复工具，明确报告恢复位置，禁止自动重试安装。成功核对新版内容和版本后才提交、清理备份。用户数据位于程序目录之外；自定义数据目录位于安装目录内时禁止自动安装，避免目录替换影响资料。

Windows CI 使用可控安装器桩验证真实文件系统上的取消、失败、进程残留和中断恢复，不证明真实 NSIS 卸载／安装或登录触发恢复的完整链路；真实 Windows 旧版到新 Stable 的升级及 CS2 / OBS 制作保护仍按[发布规则](../development/release-readiness.md)实测。

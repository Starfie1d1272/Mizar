# 类ESL 视觉复核

> 历史设计审查记录，保留原始结论与证据；当前规范见[设计系统](../../design/README.md)。

参考为 Google Drive HUD 文件夹中的 overlay4.vue 与 overlay4.zip。BLAST 是作者之前复刻的残留。新增第五个内置预设，以 `esl` variant 与独立 recipe 保存，保留 Mizar 的 Program/Radar、目标状态、库存与预设持久化所有权。

## 展示与素材

对齐 440px 比分、28px 标题、60px 绿色数字、竖排系列胜图标记；308px 五行选手栏、76px 卡片、12px 编号带、叠层头像/生命色、死亡灰阶和骷髅；240px 观战头像与36px姓名/生命带；400px 原色雷达、黑字阵营圆标、放大观察位、死亡编号、方向/开火图案、烟雾圆与燃烧区颗粒。系列地图横条放在雷达上方。文字/生命/武器始终位于背景效果之上。

使用 ESL 官网公开 Legend 字体与 Adobe 官方思源黑体，字体本地随包加载，权利记录见 THIRD-PARTY-NOTICES。缺少原纹理 text2.png，新增近似噪点/斜纹 SVG；缺少视频/摄像头资源，使用现有头像与缺失头像观察位回退。暂停、历史沿用已有播出组件。未知/过期/退出地图状态继续清除标记，地图校准、楼层与烟火生命周期不从参考移植。

## 设计系统检查

属于播出界面。固定几何与字体限定在 esl renderer，阵营/赛事/表面颜色通过已有主题变量；产品界面、共享控件和 canonical tokens 无变更。无需新增基础组件与故事；没有增加旧样式额度。现有 reduced motion 关闭开火闪烁，数据由 accepted Program/Radar 投影提供。预设备份、启用重载、组件混搭与导入导出均沿用现有受控入口。

## 验证

本地浏览器检查布局、字体加载与雷达资源；自动检查覆盖新预设的 schema/副本/保存重载、预设 pack 往返、暂停状态、雷达生命周期与 full-map 几何。运行 build、typecheck、lint、design:check 和 HUD 浏览器验收。PR CI 作为提交后检查，Windows/CS2/OBS 现场验收未在本环境执行。

地图条的两行文字明确排在 28px 内，避免沿用原版 44px 地图图片行导致裁切。选手栏 160×76 图像槽与观战卡 240×240 图像槽使用 contain，普通头像、横图与定妆照均等比完整显示；不拉伸或裁切。队标只显示比赛上下文实际提供的 Logo，示例为空不补造。

## 成熟赛事烟团与状态适配

类ESL 继续使用共用 broadcast-smoke 的云团蒙版，调整到 308×76 选手卡的头像位置并镜像左右；中性灰云团叠于头像之上、姓名/生命/武器/库存之下。闪光保留成熟状态层的亮斑与光线，改为偏白、降低强度，燃烧保留底部暖色与共用动效。局部 `--esl-effect-origin-x` 只表达头像效果的几何位置，不声明主题/状态颜色或数据事实。观战卡的三个效果限制在 240×240 图像区域，姓名/生命带不受覆盖。原有状态强度、减少动效、死亡/过期清理和 accepted Program ownership 均沿用。

本地视觉复核包含正常、全强度烟团、全强度闪光、燃烧、烟团＋闪光的左右选手卡，以及观战卡单独裁图；由同一比赛样例合成状态演示并截图实际 renderer，不代表这些状态在原始回放中同时发生。无全站像素基线。

## 暂停、历史与全状态一致性

战术／技术暂停使用 ESL 字体、直边纹理面板、绿色比分／标题和方形胜图标记；双方名单、队标、经济、库存与暂停剩余格保持完整。头像使用 contain。技术暂停不补造倒计时，战术暂停与历史仍按已证明的物理队伍位置左右互换。队伍汇总控制对 ESL 开放，作用于暂停经济栏，常规窄选手栏仍隐藏汇总槽。

冻结期横向历史与暂停竖向历史统一绿色标题、深灰纹理与 Legend 数字；阵营色仅表达当回合胜方，保留胜因、历史空缺、未来回合和加时分组。冻结期仍遵守原五秒展示窗口、开局前收起和 LIVE 隐藏。可选地图详情也统一标题／字体／材质；比分、C4 安装／已安装／拆弹、左右选手栏与 CT/T 观战卡一并复核。危险、拆弹、预测状态沿用各自语义色，不将所有状态改成绿色。

本地证据包括 CT 与 T 战术暂停、技术暂停、冻结期历史，以及已安装／拆弹的整帧预览；另保存暂停名单／经济栏、暂停信息、两类历史的单独裁图。使用既有真实回放 fixture 和静态地图背景，无现场视频。

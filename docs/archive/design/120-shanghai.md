> 历史设计审查记录，保留原始结论与证据；当前规范见[设计系统](../../design/README.md)。

本轮读取用户提供的 Shanghai01–05.webp 原文件，全部为 2940×1846。游戏画面 y=96…1749（1654px），上下各约96px黑边。统一比例 1920/2940，不对单个组件分别拉伸。WebP 压缩、视频缩放和抗锯齿仍产生约1–3逻辑像素的不确定性；这不是无损设计稿。

原图与真实 replay 的地图、队伍、数值和媒体不同。核对几何、阅读顺序、状态和视觉层级，不用整张像素差分评分。原图裁片与前后实现的本地 HTML 对照页覆盖15项，原始私人附件不作为产品资源发布。

## 数据与素材边界

- Steam 方图与参考的透明人像/视频不同；不保留视频宽框。角标避让属于此适配，而非复制原摄像头尺寸。
- RivalHub 尚未提供 shortName；现在两侧完整名称等字号，live简称仍待网站公开契约联动。
- 字体与图标使用项目资源，比赛名称、赞助素材不从私人附件中截取发布；底板补充低对比曲线纹理。
- 参考的弹药表达不能覆盖实际 GSI 数据语义；当前备用弹匣仍按来源显示，不能凭图把3个弹匣改成90发。
- 上海预测血条改为实色分段；来源不足时不补预测/计时。Focus 与选手卡统一优先显示已有 liveAdr，缺失再使用 completedAdr。
- Focus 补充当局击杀角标。视频流与赞助位依然取决于媒体来源；当前使用用户指定的方形 Steam 适配。
- 雷达沿用现有独立 Radar renderer；这组 Nuke 参考和 Ancient 回放无法比较地图纹理/楼层的逐像素一致性。
- 参考02是展开比分/经济状态；实现遵从用户明确要求，仅冻结期显示右上详情，不据单帧猜测延迟时长。

## 信息层级复刻更新

实际修改生产渲染器，而非只记录差异：Focus 的150×192信息区分为姓名、血量护甲、道具、26px统计带、弹药五层；补充媒体内侧36×54当局击杀角标、统计图标和渐变底板。死亡时仅展示源数据明确提供的0血量，不推断缺失数值。死亡选手卡调整姓名、经济、统计基线；护甲随血量排列，拆弹器/C4与道具排列，Zeus同持时单独让位；存活金额去掉千位分隔，经济展开条补阵营标识并镜像分组。比分校准字重、补细金线；拆弹面板与进度条补绿色工具标识；上海C4预测移除斜纹，采用实色区间。

检查同尺度原图裁片和生产回放的七个状态，保留570×58/800×58比分、300×84卡片、180×84死亡信息区、8px行距及左右对称；截图脚本继续断言徽标不覆盖方形头像、持有武器明暗正确。相关组件和presentation测试、Web类型检查、lint、design:check通过。新增回归验证Focus当局击杀、live ADR和已报告的死亡零值。

## Nuke 叠图与双倒计时修正

上轮 Ancient 拆弹采集窗口从已安放后开始，Core 未观测到 planting→planted，故 explosion.durationSeconds=null；渲染器因此不画fuse。拆弹条还错误使用完成比例，首帧宽度为0。上海现改用剩余比例；左条右端、右条左端分别固定，均从外侧向中间缩短。没有给缺失数据的Ancient片段硬补40秒。

新增真实 Nuke Demo 派生参考（Legacy–Falcons第1回合，265帧），经过production adapter/Core，来源及字段局限见 `fixtures/demo/nuke-lgcy-flc-round-01/README.md`。不称为实机GSI采集。以真实拆弹事件的0/3/6/9秒取帧，绿条宽164/114.80/65.59/16.39px，右端固定839px；红条宽86.44/74.42/62.44/50.44px，左端固定1081px。来源无kit，该回放不画kit标识。爆炸条由同场事件间隔派生，不能当作原生fuse netvar验收。

同尺度50%叠图发现雷达沿用了EWC分层摆放：上海现单独调整Nuke上下层display placement，地图和所有实体共用坐标变换；保留其他预设原几何。雷达也接入持久化样式变体，上海增加34%深色底板、降低地图亮度。队伍概览固定7px内边距，道具展开态每列36px、计数16px，经济标签11px；移除space-evenly造成的额外留白。Focus底行恢复当前枪械与对应弹药组合，持刀/道具不残留枪械弹药。拆弹面板文本再按叠图上移6px。

已生成Nuke实际回放视频、四帧DOM量测和50%叠图。71项受影响测试、全仓类型检查、design:check通过；视频验证两条剩余进度同时缩短。参考是2024转播，当前地图资产与比赛为2026版本，地图美术/比赛事实差异不通过替换或伪造数据消除。

## 收尾状态检查

- 安放/拆弹计时归零或不可用时，附加面板同帧撤掉；没有占位符或退出动画残留。真实 Ancient 回放覆盖安放→已下包。
- C4 缺失由用户确认是后端未启动；保留原始图标与几何，只补纯 CSS 透明度呼吸，减少动态效果时关闭。
- 道具持有高亮与 presence 动画分离；三套赛事风格的同库存持有切换立即更新。头像失败后换 URL 可恢复。
- 离线展示参考 ZIP 使用同一 renderer，固定样本与 DOM 导出无需 Mizar 后端。字体及 SVG 蒙版内嵌，原始资源和许可一并保留。正式公共 renderer 抽包继续留到后续。

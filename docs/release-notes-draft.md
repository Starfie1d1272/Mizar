本文是正式发布前的待填模板，不表示已经发布或通过实机验收。发布流程见 [RC 与发布](release-readiness.md)。

## 验证范围与已知问题

### RC1 实机反馈后的修订（待构建与复验）

- 桌面命令的字符串错误转换为可展示的错误，保留 GSI 安装、恢复和现场窗口操作的具体失败提示。
- GSI 脚本统一输出 UTF-8，修复无控制台启动时中文输出按系统代码页编码、操作成功却解码失败的问题。
- GSI 子进程自行初始化 Windows PowerShell 模块路径，修复从 PowerShell 7 启动应用时继承模块路径、无法加载 `Get-FileHash` 导致安装失败的问题；回归覆盖无控制台中文输出与配置指纹计算。
- 恢复原 GSI 配置成功后显示完成提示与重启 CS2 的说明。
- 按 OBS WebSocket 的字符串列表读取场景集合，修复真实 OBS 中已创建集合仍提示缺失、再次修复重复创建的问题；场景修复后显示检查结果。
- 进入现场时恢复窗口并切换焦点；重复双击应用唤回已有准备中心，不再静默退出新启动。
- 工具窗口通过异步桌面命令创建，避免 Windows WebView2 在同步命令中创建窗口时卡住；再次打开已最小化的工具时恢复窗口。修订需在 RC3 上检查 BP、HUD 和诊断首次打开与复用。
- 工作区与控制栏首次进入现场时以可见窗口初始化 WebView2，布局结果先取出再执行窗口操作。该修订不代表实体显示器验收已通过。
- RC4 移除工作区和控制栏的强制捕获排除，使其可用于远程制作、截图和任务栏预览；本机 HUD 覆盖也允许捕获，以便远程观察。OBS 正式输出使用独立的游戏捕获与播出 Browser Source。远程实测和实体显示器验收分别记录，不因移除保护就预先宣称空白故障已解决。
- RC5 重做固定现场布局：常驻操作无需滚动，场景按钮完整显示，设置移到独立页面；雷达等待数据时显示明确占位或已知地图底图。关闭三个现场窗口的原生阴影。进入现场前检查 OBS WebSocket 与场景配置，未通过则显示首次连接引导；OBS 启动使用其可执行文件所在工作目录。浏览器缩放模拟与实际 Windows/DPI 证据分别记录。
- RC5 修复 OBS 游戏捕获的空标题／空窗口类目标，优先采用 OBS 枚举出的实际 CS2 窗口，未启动时保留完整预设目标，并保持按进程名匹配。配置引导说明受信任模式的游戏捕获限制、启动选项与真实画面核对；不自动修改游戏服务器选择或安全启动选项。OBS 路径缺失保留可执行的恢复提示，未知错误仍隐藏内部细节。
- 保存本地比赛资料和赛事资料成功后显示明确反馈。RC1 的保存请求日志返回成功，反馈修订仍需在新 RC 上复验。
- RC1 的首次日志显示文件校验约 17 秒；上述修订仍需新 RC 实机复验，不沿用 RC1 的验收结果。

RC6 补齐本机 HUD 的缩放容器：固定节目画布放在独立视口中缩放，避免 CSS transform 保留原始页面尺寸、在小窗口中生成白色滚动条。浏览器验证包含桌面模式与窗口尺寸变化；OBS 正式 Browser Source 继续使用原始节目画布，不改变比赛事实和本机显隐策略。桌面按钮打开 OBS 时，由 Host 在服务 Job 外启动，避免退出 Mizar 连带终止 OBS；Companion 仍管理唯一的路径配置、连接与场景。

## RC7 候选修订（待 exact artifact 实测）

- 支持新鲜 GSI demo 手动 Gameplay，自动赛事及结果门槛保留；见 ADR-0025。
- 修正 Host 跟踪/命令线程的 DPI 坐标上下文，恢复布局失败有具体反馈。
- 可信实时单图结束增加 Director 所有的 3 秒 GG cue，五套 HUD 共用行为，手动/恢复不补播历史。
- Cargo 为应用版本权威，CI/build 校验 Tauri 镜像；artifact/manifest 记录 appVersion，打包核对 EXE 编译版本，晋级校验标签。
- Node win-x64 ZIP digest 固定于仓库 contract；移除按目录名称删除依赖 test/tests/__tests__ 的裁剪。
- Qualification 为成功 ZIP 生成 provenance；Promotion 下载已验证产物，校验包和二进制版本后发布，不重新构建、不覆盖不同身份的标签。

本机未发现可用代码签名证书。1.0 分发暂采用 unsigned 例外，保留校验和与 provenance；Authenticode 另排 1.0.x，证书/发布主体确认后在 checksum 与 qualification 前签名，不事后替换已发布二进制。正式 v1.0.0 仍需 #35 实机门槛。
- #132 手动回退：本机设置显示固定的原生 HUD 隐藏/恢复命令并提供复制反馈，尚未执行自动注入。

## RC8 工作台界面修订（待同一构建包实测）

- 准备中心采用统一左侧导航，总览集中显示比赛选择、摘要与开播检查；完成、问题与待确认状态分层，示例体验按需展开。
- 统一按钮、输入框、标题与状态样式，保留现有品牌标志；赛事图池改为紧凑复选行，OBS 连接分为打开、连接控制与检查画面。
- 现场左下方显示 16:9 OBS 画面，底栏保留八个场景和实际下一场景预览；宽窗口下限制 OBS 预览尺寸，避免遮住制作提醒。
- 本机 HUD 提供雷达与其他 HUD 两个独立开关；CS2 原生 HUD 的隐藏、恢复命令并排显示，复制反馈明确尚未在游戏中执行。

本次不自动修改 CS2 的分辨率、画质或 Steam 启动选项。浏览器验收与构建自动化不替代 Windows、CS2、OBS 和 DPI 的实机验证；验收范围继续由 #35、#90、#112 跟踪。

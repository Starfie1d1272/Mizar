## 这版可以做什么

Mizar 把 CS2 赛事的准备、画面、现场控制和故障诊断放进一套中文、本地优先的制播工具：

- 从准备中心创建本地比赛、复用队伍与资料，或授权连接 RivalHub 加载赛程。
- 安装／恢复 GSI、检查／修复 OBS 场景，预览后进入现场 Workspace。
- 显示 HUD、雷达、系列地图与比分，使用默认或类 EWC、类 IEM、类 Perfect World 预设。
- 编辑并保存自己的预设；选择和保存不会直接上屏，确认启用才改变正式节目。可通过 `.mizar-hud.json` 分享受控配置。
- 自动编排赛前到赛后的节目流程；需要时手动接管，再显式恢复自动。
- 使用随包十图资源显示可关闭的 C4 站立伤害估算；在最后十秒显示有效覆盖层，不改写真实血量。
- 遇到问题时使用设置检查、日志与有界诊断导出，便于保留版本和故障阶段。

最终默认 HUD／节目场景美术说明与截图：待设计冻结后补充，当前不将重绘列作已完成能力。

## 安装与恢复

Windows x64 用户完整解压到可写目录，双击 `Mizar.exe`。包内自带 Node，桌面需要 Microsoft Edge WebView2 Evergreen Runtime。按 [快速开始](quick-start.md) 完成 CS2、GSI、OBS 和比赛准备。

保留旧产品包与 `state` 备份；当前不承诺通用自动升级／格式迁移。不要删除数据目录或自行替换资源作为常规修复。结束制作与停止推流是独立操作，完整退出通过托盘「退出 Mizar」。

## 已知限制

- C4 是当前位置与站立姿态的估算；不提供真实姿态观测、站／蹲双值、native exact 或必死／必活保证。十图资源不等于十图实机精度全部通过；未来 CS2 更新可能需要资源更新。
- 未支持地图、资源异常、缺失输入或过期数据会隐藏预测；回合结束、暂停或有效倒计时窗口外也不显示覆盖层。
- 自动编排依赖有效比赛与 OBS 状态，手动保持或异常暂停后需要显式恢复；预览和连续演示不证明正式切场成功。
- Lookahead / Observer Assist 仍是独立增强方向。RivalHub 连接与恢复链路另有适用验收，当前不承诺赛事运营、现场制播和赛后分析的一键云端闭环。
- 社区视觉包分发、通用插件、installer／auto-updater／signing 的长期形态不属于当前便携版交付声明。
- 待最终实测：补充实际已知问题、未验场景和关联 issue；有 blocker 时不能以本草案宣称正式生产 PASS。

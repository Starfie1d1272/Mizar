# Mizar 1.0 发布说明草案

本文是正式发布前的草案。当前发布物为 [RC22](https://github.com/Starfie1d1272/Mizar/releases/tag/v1.0.0-rc.22)，不是正式1.0；现场验收由 [#35](https://github.com/Starfie1d1272/Mizar/issues/35)、发布门槛由 [#90](https://github.com/Starfie1d1272/Mizar/issues/90) 维护。发布步骤见[RC与发布](release-readiness.md)。

> 让校园赛事，也有职业赛场的转播呈现。

Mizar 将自动节目流程、制播工作台、HUD与雷达、赛事连接组织为本地CS2制播系统。产品范围见[产品定位](product.md)，操作步骤见[使用手册](quick-start.md)，实际画面见[Windows真实demo图集](screenshots/windows-rc22/README.md)。

## 当前交付

- 候选应用版本：`1.0.0-rc.22`，Windows x64完整便携ZIP与自解压包；下载及校验和以Release资产与清单为准。
- 包源码：`6e84cd2eaa027ae322ad486b6b2ab31e18e2d486`。资格构建与原产物晋级均成功，没有重新构建或覆盖历史RC。
- 正式版本、最终包源码与已验RC的对应关系：待正式发布门槛满足后冻结，不提前填写正式下载链接。
- 当前分发采用未签名例外；Authenticode、安装器与自动更新按既有后续范围推进，不事后替换已发布二进制。

## 本轮收敛的行为

- 准备中心默认最大化，游戏配置检查和恢复入口显示稳定；受管理游戏按实际工作区尺寸启动，现场左栏、底栏与任务栏布局协调。
- 半场、单图结果、图间和整场结果支持人工选择；缺少可证明统计时明确等待，不补造赛果。GG提示在比分栏中央，五套HUD共用比赛语义。
- C4预测按整帧更新，爆炸到真实生命值更新之间有独立且有上限的视觉衔接；5秒和10秒拆弹依据连续动作证据展示，未知钳子状态不冒充无钳。
- 烟雾展示容忍单次寿命回跳，并在同一连续生命周期保留已知阵营；五套选手卡片共享固定K/D数字列。
- 真实同图重播的热身/零回合/零比分清除旧执行历史；末局gameover帧先归约完整历史和有效统计，赛后晚到K/A/D在可信同一执行中收敛，已经确认的比分与历史保持冻结。
- Steam Web API Key可选且推荐填写；设置提供官方申请入口与域名填写说明，配置后由本机服务加载真实Steam头像。
- 正常结束制作共用安全切场、源释放、受管理游戏退出与视频恢复；托盘隐藏和退出是两个明确操作。

## 验证范围与限制

原故障Windows机器的RC22资源管理器双击冷启动、可操作界面、无空Node窗口、正常退出及再次启动通过。最终RC22末局定点实测十人结果K/D与实时观测一致，五套数字格无溢出；新职业demo十名选手Steam头像与两队身份实际匹配。

旧RC21完整Nuke/Mirage与长时采集、旧RC20完整三图、C4/拆弹/烟雾等证据保留各自构建范围，不能转写为RC22完整验收通过。**原生雷达仍有偶发长间隔**，追踪已发现画布像素读回/命令缓冲等待相关片段，但没有解释全部间隔；该问题继续在 [#149](https://github.com/Starfie1d1272/Mizar/issues/149) 收敛。

最终同包完整多图与统计、自动及人工全流程、显示器/DPI矩阵、OBS服务恢复和最终退出恢复仍按#35逐项验证。公网推流、Steam Cloud延迟/取消及平台条件场景只按实际完成情况记录，不由本地回放或旧版本地RTMP替代。

## 安装、升级与反馈

完整解压到可写目录后运行`Mizar.exe`。首次准备、恢复与诊断导出见[使用手册](quick-start.md)。已验证升级和恢复路径随正式发布填写；保留旧包与数据备份，不混拷不同构建资源。

反馈入口：[GitHub Issues](https://github.com/Starfie1d1272/Mizar/issues)。许可证、参考与资源来源见[第三方说明](../THIRD-PARTY-NOTICES.md)。

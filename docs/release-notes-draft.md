## 验证范围与已知问题

### RC1 实机反馈后的修订（待构建与复验）

- 桌面命令的字符串错误转换为可展示的错误，保留 GSI 安装、恢复和现场窗口操作的具体失败提示。
- GSI 脚本统一输出 UTF-8，修复无控制台启动时中文输出按系统代码页编码、操作成功却解码失败的问题。
- 恢复原 GSI 配置成功后显示完成提示与重启 CS2 的说明。
- 按 OBS WebSocket 的字符串列表读取场景集合，修复真实 OBS 中已创建集合仍提示缺失、再次修复重复创建的问题；场景修复后显示检查结果。
- 进入现场时恢复窗口并切换焦点；重复双击应用唤回已有准备中心，不再静默退出新启动。
- 工具窗口通过异步桌面命令创建，避免 Windows WebView2 在同步命令中创建窗口时卡住；再次打开已最小化的工具时恢复窗口。修订需在 RC3 上检查 BP、HUD 和诊断首次打开与复用。
- 保存本地比赛资料和赛事资料成功后显示明确反馈。RC1 的保存请求日志返回成功，反馈修订仍需在新 RC 上复验。
- RC1 的首次日志显示文件校验约 17 秒；上述修订仍需新 RC 实机复验，不沿用 RC1 的验收结果。

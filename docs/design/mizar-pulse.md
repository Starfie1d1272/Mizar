# Mizar Pulse：默认 Gameplay 包装

本规范由本轮用户评审确定：深色主壳、冷白高对比读数、强品牌蓝、少量暖金伴星。替代上一轮冰白战斗带，直接升级现有默认 HUD；不新增第六套预设。仅覆盖 Gameplay 及 live / freeze / pause / death / objective 状态，BP、Waiting、Matchup、半场、图间、结果页组织不重做。

## 固定颜色与职责

| 品牌蓝 | `#2D7FF9` | 上沿能量边、暂停品牌色面；默认 CT 强调 |
| 蓝色高亮 | `#59A8FF` | 当前地图、观察者边缘、渐变前沿 |
| 冷白 | `#F4F8FD` | 比分、HP、当前武器、姓名 |
| 辅助灰 | `#9AA8B7` | K/D、统计标签、状态辅助文字 |

## 共同造型与材质

主壳为直边与 4–6px 小圆角；深壳中用身份/战斗分层，冷白只承担核心读数，不给每个读数建立白盒。极低对比度的斜向细线在深底可见，头像与地图图像保持原素材。蓝色能量边在比分、地图、雷达、选手、Focus 与暂停共同出现；暖金限于事实强调和小节点，不铺满右队。品牌不依赖添加 Logo、复杂切角或月牙。

## 动效与状态

模块出现与 freeze / pause 的新模块使用 220ms 短暂提亮。观察者边缘以 2.4s 低幅蓝色脉冲表达选择，不移动信息。下包、拆弹和目标结算通过实际 `data-objective-mode` 切换短促闪动；不同动画名称仅用于重启同一节奏，不建立时间/比赛状态 owner。CSS 材质不新增持续计时或数据通道。

`prefers-reduced-motion: reduce` 停止默认组件的动画与非必要过渡，保留比分、目标进度、生命比例与状态信息。freeze 仍显示实际装备/经济；pause、死亡、目标动画均由原投影和设置驱动，不制造缺失事实。

## 检查与边界

需检查同一比赛投影、同一 Steam 头像、同一背景、1920×1080 与相同缩放下的 live、freeze、pause、多人死亡、Focus、长中英文昵称、满装备。四套参考只用于形状/节奏对照，不把职业定妆照当作布局优势。实际证据与验证限制见 [视觉复核](reviews/mizar-pulse.md)。

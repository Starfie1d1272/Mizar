# Mizar Pulse：默认节目包装

本规范由本轮用户评审确定：深色主壳、冷白高对比读数、强品牌蓝、少量暖金伴星。替代上一轮冰白战斗带，直接升级现有默认 HUD；不新增第六套预设。覆盖八个默认播出场景及 Gameplay 的 live / freeze / pause / death / objective 状态。所有场景保留主要布局，统一配色、材质与信息主次。产品与诊断界面不套用本包装。

## 固定颜色与职责

| 用途 | 色值 | 职责 |
| --- | --- | --- |
| 主背景 | `#0E131A` | 雷达外壳、画面深度；不遮住游戏背景 |
| 模块深壳 | `#141B24` | 比分核心、战斗信息、Focus、暂停 |
| 次级壳 | `#1B2531` | 身份层、模块分层 |
| 品牌蓝 | `#2D7FF9` | 上沿能量边、暂停品牌色面；默认 CT 强调 |
| 蓝色高亮 | `#59A8FF` | 当前地图、观察者边缘、渐变前沿 |
| 冷白 | `#F4F8FD` | 比分、HP、当前武器、姓名 |
| 辅助灰 | `#9AA8B7` | K/D、统计标签、状态辅助文字 |
| 暖金 | `#F0B84B` | 少量收边、系列胜图标记；默认 T 强调 |

## 共同造型与材质

主壳为直边与 4–6px 小圆角；深壳中用身份/战斗分层，冷白只承担核心读数，不给每个读数建立白盒。极低对比度的斜向细线在深底可见，头像与地图图像保持原素材。蓝色能量边在比分、地图、雷达、选手、Focus 与暂停共同出现；暖金限于事实强调和小节点，不铺满右队。品牌不依赖添加 Logo、复杂切角或月牙。

## 动效与状态

模块出现与 freeze / pause 的新模块使用 220ms 短暂提亮。观察者边缘以 2.4s 低幅蓝色脉冲表达选择，不移动信息。下包、拆弹和目标结算通过实际 `data-objective-mode` 切换短促闪动；不同动画名称仅用于重启同一节奏，不建立时间/比赛状态 owner。CSS 材质不新增持续计时或数据通道。

`prefers-reduced-motion: reduce` 停止默认组件的动画与非必要过渡，保留比分、目标进度、生命比例与状态信息。freeze 仍显示实际装备/经济；pause、死亡、目标动画均由原投影和设置驱动，不制造缺失事实。

## 检查与边界

需检查同一比赛投影、同一 Steam 头像、同一背景、1920×1080 与相同缩放下的 live、freeze、pause、多人死亡、Focus、长中英文昵称、满装备。四套参考只用于形状/节奏对照，不把职业定妆照当作布局优势。实际证据与验证限制见 [视觉复核](reviews/mizar-pulse.md)。

## 全场景衔接

| 场景 | 固定组织 | Pulse 表达 |
| --- | --- | --- |
| Waiting | 赛事、双队、计划时间、前后场赛程 | 标题 84px、队名 52px；深壳赛程、蓝上沿；大弧面整体透明度 0.14，前沿改蓝色高亮，不用高亮白面压住内容 |
| Matchup / Intro | 双队标/队名、地图标题、进入 HUD 的落位动作 | 冷白字、地图标题蓝线、暖金小节点；短时弧面自身透明度 0.10；既有 2s/6s duration 与 director 时序不改 |
| BP | 七图顺序、禁选动作、选边与逐步揭示 | 深壳、小圆角、PICK 蓝上沿、DECIDER 金上沿、BAN 减重；地图照片保留原彩色，禁用才灰化；文字保留动作与事实，金色不表示胜方 |
| 半场 / 图间 | 上方地图条、双方队伍、十人镜像 K/D | 深壳选图标签，当前图蓝色局部强调；隔行用 shell/raised 分层，不使用亮灰隔行；标题与比分优先，地图与头像槽固定 |
| 单图结果 | 两侧超大比分、队标、地图底图、系列小比分 | 大比分冷白，地图标题亮蓝；去队标方框，确认的本图胜方保留冷白下沿；地图底图继续低对比 |
| 整场结果 | 系列比分、地图条、最后一图十人统计 | 顶部系列比分 48px，半场/图间同位置 36px；只有 series completed 且达到 requiredWins 的一方才显示队名强调，未完成不推断冠军 |
| Gameplay / Pause | 既有组件、固定行位与状态分权 | 沿用上表；补齐地图详情、存活人数和备用暂停卡；暂停中间品牌蓝混入深壳，仅保留 36% 蓝色面 |

除 Waiting 外，全屏信息页弧面透明度为 0.06，并移至画面边缘；不在每张卡上重复弧面。静态壳体使用 Pulse 变量，正文不铺满纹理与发光。比分、昵称与中文字体沿用既有两类字体。BP 的 4px 小圆角使用 canonical `shape.control`，不新增 BP 产品界面主题。

HUD 已实现的 8 个 renderer（比分、左右两侧选手栏、Focus、雷达、地图条、地图详情、历史）与内嵌暂停/目标/状态效果均纳入复核；`objective` 和 `round-result` 独立槽仍维持原来未实现的 registry 状态，目标与回合结算由现有比分组件承载，本轮不新增功能。

完整画面、默认关闭组件的 opt-in 截图与边界样例见 [全场景复核](reviews/mizar-pulse-scenes.md)。

# Mizar Pulse 默认节目包装

Mizar Pulse 统一默认 HUD 与赛前、半场、图间、结果等节目画面：深黑蓝底、冷白核心读数、品牌蓝强调、少量暖金节点。产品和诊断界面仍遵循自身规则。

## 视觉层次

- 比分、生命、当前武器与姓名优先；统计、经济和道具按用途降低权重。
- 深色模块采用直边与小圆角，区分身份和战斗信息；不用白盒包裹每个数字。
- 蓝色细边贯穿比分、雷达、地图、选手与暂停；暖金只强调少量节点，不铺满右队。
- 头像与地图保留原素材，低对比纹理与弧面不穿过主要读数、不抢赛事身份。
- 阵营色随真实 CT/T 改变，不由物理左右决定；危险红只表达危险事实。

精确值由 [设计变量](../../packages/design-tokens/src) 的 `color.pulse → brand.pulse → broadcast.pulse` 和 [默认外观方案](../../packages/hud-config/src/presets/default-theme.ts)维护。字体、几何由对应组件与布局定义，不在文档复制像素表。

## HUD

| 组件 | 视觉规则 |
| --- | --- |
| 比分条 | 连续深色核心，大比分与时间；目标信息在稳定区域内替换 |
| 选手栏 | 固定五行、两侧镜像；边端头像与生命/武器层明确，死亡只收短可见底板，不移动姓名与整行 |
| 当前观察选手 | 紧凑横向战斗信息；弹药与姓名互不挤占，统计开关不破坏边界 |
| 地图条与雷达 | 统一深壳和蓝色边缘，保留地图原色、事实颜色与楼层层次 |
| 暂停 | 经济、名单与赛事身份同画布组织，冷白读数与受控品牌强调 |
| 回合历史 | 区分已知、缺失与未来；阵营色按历史回合事实，不套当前换边关系 |

## 节目场景

| 场景 | 组织方式 |
| --- | --- |
| 赛前等待 | 赛事、双方、计划时间、前后赛程；没有邻近赛程则收起对应区域 |
| 对阵开场 | 短时呈现双队身份，队标衔接当前 HUD 的实际位置 |
| BP | 保留地图图像与禁选顺序，选图突出、禁图减重、决胜图独立标识 |
| 半场与图间 | 地图条、双方与十人镜像统计，固定媒体槽和数字列 |
| 单图结果 | 大比分与队标优先，地图背景低对比，明确本图胜方 |
| 整场结果 | 系列比分与地图条优先，选手表明确最后一图统计 |

## 动效与缺失状态

短暂提亮和低幅脉冲表达状态变化，不移动关键读数。目标进度与动画只消费已有投影，不建立浏览器游戏计时。减少动效时停止非必要动画，保留信息与节目时序。

缺头像、队标或数据时保持清楚的缺失表达；长中英文名称、满装备、暂停、死亡与目标状态均需复核。同一配置应在编辑器与正式节目使用相同渲染结果。

当前图像见[预览图集](../screenshots/README.md)，设计演变见[历史审查](https://github.com/Starfie1d1272/Mizar/tree/70ec10084c13e2b634f0c12749a8ebe4c1c25c5f/docs/archive/design)。其他四套 HUD 不随默认外观更改配色。

原生选手栏以白色观察编号高亮当前视角，不使用整卡蓝色描边或循环脉冲。Focus 阵营色条归属于各选手卡面，与选手切换一同淡化；手持道具图标适配其槽位。只有实际 BP 或 pick/decider 证据才显示比赛中的地图条。C4 当前输入等待计算时显示中立更新指示，不沿用旧位置估算。

没有可见系列地图条时，默认位置的雷达上移到地图条原位置；显式编辑的偏移不自动改动。本回合击杀圆徽与 K/D 数字行共用垂直中心，预留两位数列和徽标间距，保留五人槽位和卡片高度。雷达 C4 使用图标本体，不绘制红色圆底板；已安放目标使用低幅透明度呼吸，减少动效时保持静止。烟雾纹理和火焰模糊可缓存，时间、阵营轮廓与坐标仍逐帧消费当前展示模型。

# #106 节目编排第一版

本版供视觉与节奏评审；不替代真实 Windows / CS2 / OBS 验收。默认节目包为 `builtin:mizar-default`，赛事名称、赛事标志、参赛方媒体独立于产品品牌。

## 预览

准备工作区 → 画面 → 节目预览，或独立节目预览工具。选择 Waiting、对阵、半场、单图结果、图间、整场结果；对阵可“重播开场”。BO1 / BO5、缺少媒体、长名称均可直接切换。预览只读真实回放衍生样例，版式变体明确标记，不写入 Runtime，不伪装为现场数据。生产路径不读取预览样例。

## 编排

进入现场后自动工作，手动 Take 后保持，点击“恢复自动”才交回。准备阶段和既有赛事排练不会被自动推进。底栏显示当前播出、下一场景、自动/手动/阻断及原因。

Warmup 的 BP 完整揭示一次，最终板停留 2s 后回 Waiting。首回合 freezetime 根据语义时钟预算选择 BP 最终板 → Intro → HUD、短 Intro → HUD 或直接 HUD；已经 Live 不补播。真正的常规半场覆盖短 intermission、长 paused 和第二半场 freezetime；加时换边不生成半场画面。单图结果后进入图间/整场结果；过期或暂停停止推进，OBS 失败等待恢复。

集中参数位于 `apps/companion/src/program-scenes/director.ts`：BP 最终板 10s、完整 Intro 6s、短 Intro 2s、HUD 提前稳定 9s、半场提前退出 5s、单图结果 12s。这里是本版的调整入口，尚未增加时长编辑器。

## 展示边界

统计只使用当前图的头像、昵称、K/D，缺失为 `—`。整场结果保留系列地图条，选手表明确标注“最后一图，非跨图合计”。地图结束时同步冻结快照，最多五图；换图保留，换比赛/上下文清除。短时断流保留最后安全的静态画面。

等待页优先展示当前比赛，已取得的后续场次优先于上一场；没有邻近赛程就收起。计划时间不作为倒计时。没有图片就折叠槽位，不生成假队标或头像。背景使用确定性抽象图形，地图缩略图仅出现在地图条。

## 设计检查

播出画面使用共享文字/背景/边框变量；没有新增页面主题、动态比赛颜色通道或共享组件。现场控制和预览使用现有 Button / Select，保留键盘焦点、禁用和状态文字。固定 1920×1080 几何及 Intro 的半透明黑色 Game Capture 遮罩属于本 renderer 的播出例外；不会扩展产品界面的样式例外。删除旧 `--scene-ink` 与其精确迁移条目。

浏览器检查覆盖五种版式的尺寸、两侧对称、缺图折叠、单图比分锚点、Intro→HUD 和减少动效。减少动效隐藏交汇装饰并取消位移，保留相同内容和交接节奏。完整字体、真实 OBS 切场延迟和多机输出感受仍需要原机评审。


## 本地视觉评审

`/preview` 使用同一生产 renderer，提供全部场景、BO 版式、无媒体、长名称、缺邻近赛程，以及 6s / 2s 开场重播和透明底切换。开场和 Gameplay 样例共用同一份变体转换，队名、队标、头像与 BO 同步；HUD 读取 Companion 已启用的配置，服务不可用时沿用配置客户端的默认值或最后有效值。等待样例摘自 `fixtures/rivals-rehearsal/rivals-rehearsal.generated.json`，时间和对阵保留来源，按历史赛前画面隐藏当前和下一场的已知结果；不写入运行时。开场地图背景仅是官方缩略图的静态构图示意，不代表 CS2 实机录像。正式开场保持透明，背景由 OBS Game Capture 提供。

本轮播出画面复用既有语义变量与 BP 展示字体方向，没有新增主题或动态颜色通道。地图条保留 180px 高度、24px 队标留白和可折叠媒体；统计板继续共用 780 / 120 / 780 网格、5×120px 行，中央重复 K/D。底部赛事身份为主，既有 Mizar 标志作为次级署名。单图结果只保留 series map-wins 数字，删除重复标签。新增样式只属于 `ProgramScenePage` 的固定播出几何；预览控件复用 Button / Select，保留键盘焦点和减少动效。

开场以浏览器合成动画连续播放；初始加载、暂停/恢复或超过 1s 的漂移才校准服务端时间，避免每次轮询反复 seek。HALFTIME 退出要求正数 freezetime countdown 或可信 live。真实 Windows / CS2 / OBS 延迟与最终 60fps 捕获仍由平台验收证明。

共享统计板只显示 K–D，中央每行标记 K/D；assists 仍保留在原有快照契约中，renderer 不显示。默认预览的第三图 DECIDER 复用已有 `series-bo3-map1` 展示计划，与真实遥测来源分开标明；生产画面只认 canonical selection。`/preview` 中 BP 与其他场景共享一个预览视口，直接装载 `/program/bp`。播放、收起、BO1/BO3/BO5 演示和本地录入均在 BP 标签内操作，继续使用既有 BpSession；这些控制会影响当前 BP 播出，界面明确标注，与只读连续转场演示区分。切换场景或连续演示仅隐藏 BP 控制，保留当前未保存的编辑；删除静态 BP fallback 和独立工作台布局。浏览器与桌面入口复用节目预览窗口。旧 `/operator/bp` 仅保留重定向。

### 统一转场

普通自动切场为 300ms 淡化，返回 Gameplay 为 150ms；开场到 HUD、手动 Take 及紧急返回比赛为 Cut。BP 跨场景退场由同一次淡化承担，完成后收起会话；单独收起保留 360ms 动画。统一预览支持只读连续演示、停止和立即切入比赛，静态页停留 3 秒，开场保留 6s / 2s，当前 BP 未显示时跳过。预览最多两层，完成后回到单层，快速选择不排队。

界面审查：产品预览控件继续使用 Button / Select 与现有 token；转场是播出 presentation policy，不新增主题、比赛颜色或共享基础控件。新视口只服务节目预览。验证键盘焦点、减少动效直接切换、加载错误、快速操作与停止；浏览器证据不能代替真实 Windows / OBS 转场验收。

## Mizar 原生转播包装（默认升级）

当前默认 HUD 与节目场景共用冷黑/深蓝灰、钴蓝与冰白开口弧面、克制的暖金节点，以及 Barlow Condensed 展示字 / Inter 正文 / 中文回退。共用全屏材质和既有字体声明集中在 `broadcast-material.css`，只作用于全屏节目页和 BP 播出画布；不影响产品界面、Gameplay 透明层或三套赛事 HUD。

Waiting 使用 1120px 主内容、80px 间隔、480px 邻近赛程的布局。赛事身份在上方，当前双方的真实队标与名称居中，实际计划时间在主区底部；右侧先下一场、后上一场，每场的两个队名分行、比分使用独立列。224px 队标是主形态，缺媒体只是兼容。大弧面在信息区下方展开，不围住队标或穿过赛程文字。无邻近赛程主区扩展为 1680px。无图片或加载失败时收拢媒体行，不造缩写队标；没有比赛时保留中性开播提示。时间只是计划时间，不新增倒计时。

Matchup 是透明交接：开口弧面短暂掠过，两侧身份由向内扩展的弧形遮罩揭示；弧面在识别停留前退出，随后队标缩至正式 HUD 对应队标槽，名称退场，HUD 稳定显现。没有长驻大底板或循环轨道。目标使用生产 DOM 的实际边界，并除以画布缩放系数；不写死预设坐标。缺图使用队名，目标槽关闭或不存在时只退场。完整 6s / 短版 2s 预算和 skip 规则不变；短版省去地图、系列和暖金节点，并减少弧面的位移与停留，不把完整序列加速。字体/图片就绪后动画加入已接受的播放位置，取消时销毁，减少动效停用弧面和裁切/位移。Director 仍是唯一编排与时长 owner。

BP 只统一字体、背景材质、明暗与选图身份文字；取消 A/B 固定蓝黄分组，地图列、pick/ban 宽度与揭示流程保持。Halftime / Intermission / Match Result 仅更换共用背景材质，地图条、比分、780/120/780 十人统计网格、署名均保持。Map Result 只继承背景；大比分、队标和胜方表现不重做。没有冠军海报化，也没有改变统计范围。

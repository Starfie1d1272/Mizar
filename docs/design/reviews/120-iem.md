# IEM 参考复核与共用暂停

参考为用户 HUD 文件夹中的 IEM01–09 及 Shanghai06。HUD 固定标签保持英文；队伍、赛事和阶段保留已有来源名称。IEM09 是下半部分构图，不能用它推测完整摄像头场景。当前实现沿用 Gameplay 画布与游戏背景，由 accepted clock 的 tactical/technical pause 状态自动换编排。

## 采用的结构

- IEM01/02 的紧凑蓝色比分、顶部赛事细条与左右阵营语义；地图条按用户要求保持既有方案。
- IEM04 的大面积低透明度烟雾。三套共用烟雾轮廓，但 IEM 带少量阵营色、EWC 冷灰且斜切、上海柔和中性灰。图层位于头像与底板上方、关键信息下方，原闪光规则不变。
- IEM07/08 的外侧身份与内侧战斗信息；Steam 方形头像放在最外侧，避免误套中置定妆照的构图。
- IEM09 的连续经济/比分横栏、五行紧凑阵容与赛事中心区。中部赛事为主、播出品牌为辅；赛事 Logo、平台、赞助素材有显示接口，当前不新增配置 UI 或素材持久化。
- Shanghai06 的暂停方提示与对侧竖向历史。暂停方跟随 entrant A/B，不固定为 CT 左。历史使用当回合胜方 side；不使用当前换边映射猜测历史 team。

## 栏位与层次

暂停底部阵容距离下边缘 110px。左右各 620px，中间 640px；每行头像 32px、装备 296px、经济 88px，其余空间留给姓名。装备内固定头甲/钳/C4/Zeus、投掷物、副武器、主武器四栏；保留空槽、五行纵向对齐，每栏内容向画面中心对齐。主武器最大，副武器次之，投掷物和头甲保持较小尺寸与细分隔。

暂停小卡片保留真实倒计时和剩余次数数字。底栏用格子表达剩余次数，填色数直接读取 `timeouts_remaining`。常规三格、加时一格是用户定义的 MR12 展示规则；游戏只发布剩余次数，没有总次数。更大的实际计数扩展格数，缺失或未知阶段不伪造已用次数。技术暂停没有浏览器重建的游戏倒计时。

本轮修正的是组件内部镜像：右侧暂停小卡片的队名/标签、次数/倒计时及色边均换位，EWC 切角单独镜像。比分经济栏、选手行、提示和品牌拆为独立组件及 CSS，组合层不再持有全部细节；左右复用 DOM 和命名栏位，武器朝向只由共用素材叶节点控制。问题位于呈现规则与检查覆盖，现有 Program entrant/side 映射无需重写。

## 两种历史

暂停历史始终显示最近半场 12 格，或最近一次加时 6 格；胜因包括 elimination、bomb、defuse、time 和 unknown。暂停方倒计时在本侧，历史在另一侧。技术暂停及无法解析归属时使用中性提示。

冻结历史使用三套共用的 720×84 横条，每三个已结束回合显示五秒，并在开局剩余三秒、LIVE 或数据过期时立即隐藏。五秒仅控制展示窗口；倒计时仍来自 accepted Program。source generation、map epoch、seek revision 重置窗口，普通 accepted packet 不延长窗口。

## 保留与接口边界

保留地图条、原版 HUD、上海直边生命和 EWC 44/76 斜率/C4 预测。没有教练、语音活动或官方定妆照数据时不补造。赛事 Logo 由宿主可选 `broadcastBranding` 传入；默认只展示已有赛事名称，不把第三方赛事商标硬编码进通用 HUD。

属于播出画面，复用 canonical tokens、Theme recipe、已有 Program joins、资产与 registry；新增组件仅服务 Gameplay，未创建共享基础控件或局部主题。只新增受控展示窗口，不改 Core、协议、官方事实 owner、OBS Take 或持久化坐标。HUD 无交互控件；检查缺失图片、未知历史、source reset 与减少动效。截图只供审查，不作为像素 golden baseline；Windows/CS2/OBS 仍使用 exact artifact 验收。

## 本轮本地验证

- Web/hud-config 单测 286 通过，包括两种历史生命周期、历史胜因/中性空缺、换边暂停归属、三格/一格与实际计数、设置隐藏和 Radar 独立边界。
- 全工作区 typecheck、Web build、修改 TS/TSX ESLint、Prettier 和 diff whitespace 通过；设计契约 99、浏览器组件检查 13 通过。字体经现有品牌资产复制流程包含在 dist 中，Vite 仍打印其既有路径提示。
- 共享 renderer 36 个真实 replay 状态，另检查三套长队名/缺头像边界、减少动效与五秒历史窗口。实际测量装备各列五行同 x、无图标越栏；暂停末行底部 970px。页面异常与缺失图片为零。
- 预设设置/保存/磁盘重载/启用/Program、三套风格、配置文件交换和混用方案尺寸共四条浏览器验收通过；三套左右暂停同时检查小卡片内部坐标/色边、选手行各栏顺序和可见枪械素材恰好一次翻转，普通选手卡同样检查实际朝向。
- 使用静态地图缩略图作审查背景；本轮未新增真实 Windows/CS2/OBS 验收证据，截图不进入仓库或 golden baseline。

## 收尾状态检查

IEM 的 K/A/D/ADR 设置不再被 CSS 强制隐藏。默认关闭以保持紧凑呈现；手动启用时扩展到同一 176px envelope 内的 136px 主体，浏览器确认统计完整可见。EWC 与 IEM 的默认值、持久化 opt-in 共用配置回归；三套道具持有切换和头像换 URL 恢复均覆盖。

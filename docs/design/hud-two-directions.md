# Gameplay HUD 双方案预览

HUD 编辑器的「HUD 设计」提供同一时刻的视觉比较。`/operator/hud?mode=replay&design=arena` 为 A「竞技场」，`design=studio` 为 B「演播室」；选择「现有版本」返回原有编辑方式。两套为本地审阅方案，不写入或激活已保存预设。两套风格计划同时作为内置可选 HUD 预设交付，用户自行选择；正式接入沿用已有的 preset / variant 与 Theme 配置，保存、启用和 resolved snapshot 生命周期不另建通道。当前仍处于视觉审阅阶段。

## 视觉方向

- A：整卡血量色块、向内收的长斜边与独立三角编号、浅色中央比分区。比分、血量和弹药复用已随包交付的 Barlow Condensed 展示字体；姓名与辅助信息使用 resolved HUD 字体。以用户提供的 EWC 原图为参考：完整矩形队标区夹住白色倒梯形比分区；宽头像区，姓名、统计与经济纵向排列，主武器与 HP 位于上半行。编号独立位于斜边上端三角内，内容不侵入裁切区。
- B：较窄的直边卡片、深色身份行、下半区血量载体、小头像。交战时突出武器、HP 与剩余道具；个人经济在冻结时间显示，稳定统计在死亡态保留。
- 两套均使用当前 Theme 的中性背景、文字、CT/T 与目标颜色，经 `color-mix` 调整色块明暗。没有新增运行时颜色或手绘 CS2 素材。头像与武器保持真实素材，未知血量不绘制填充。
- 两套沿用相同的组件外框和 entrant 左右位置；内部可见卡面宽度不同。死亡、缺图、下包、拆包与暂停均不推动其他组件。

## C4

保留既有居中 C4 图标、安装进度与拆弹环形进度，不新增中文状态说明。播出 HUD 的固定状态文案使用英文；编辑器使用中文。安装密码格随当前 action 进度依次显示 1–4 格，只有已安放状态变红；缺少进度时不补造密码格。比分下方剩余时间条保持居中，两侧向中间收缩。安装完成只做短淡入，不缩放或位移图标；危险状态保留局部指示灯，减少动效关闭动画。进度继续来自 Core，跳转、重播和 source boundary 使旧动效失效。

C4 伤害预测保持 #52 的独立接入边界，本预览不生成模拟伤害或未来 HP。

## 复用与检查

- 复用 `HudConsolePage`、`HudCanvasPreview`、`GameplayHud`、现有 widget registry 和 `@mizar/replay`，不复制播放器、Runtime 或 adapter。
- Ancient 第 3 回合为完整真实 capture 衍生回放；第 11 回合仅为拆包片段，不能称为另一个完整回合。
- 两套可在不重启回放的情况下切换；播放、暂停、重播、键盘时间轴与事件跳转沿用已有控件。地图背景来自官方素材目录，是静态预览底图，不是同步游戏视频。
- 审查满员、残血、死亡、安装、已安放、最后十秒、拆包、长名称、无头像、减少动效，以及从后段跳回开局。正式 Windows / CS2 / OBS 验收独立进行。

## 设计系统审查

属于播出画面和现有产品预览工具。产品控件复用 Button / Select 和现有焦点、加载、错误状态；没有新增共享基础组件。固定像素、切角、组件内排版和局部关键帧属于 `hud-designs.css` 的播出几何。颜色和字体来自已有 Theme / canonical tokens，未扩大旧样式额度。既有版本保留用于同源比较，两套方案共享重绘规则，不形成第二份业务组件。

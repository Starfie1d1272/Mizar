# 品牌与赛事身份

Mizar 是制播主体，Alcor 是观察辅助方向的名称，两者采用相伴双星的品牌概念。正式节目与观察辅助遵循独立的数据边界；Alcor 按后续研究计划推进。

产品入口与工具使用 [apps/web/public/brand](../../apps/web/public/brand) 的既有标志，保持比例、颜色和留白，不自行重绘。桌面图标由桌面资产源管理。

播出画面以赛事名称、队伍、选手与赛事标志为主，Mizar 只作次级制作署名。缺媒体收拢或保留合适占位，不制造队标、赞助商或赛事身份。

Mizar Blue 在产品界面承担交互、选择与焦点；比赛阵营、赛事身份与状态颜色各有独立含义，规则见[界面规范](ui-system.md#颜色职责)。默认播出使用 [Mizar Pulse](mizar-pulse.md)，不把其装饰直接套到产品和诊断界面。

HUD 参考风格名称用于说明视觉方向，不表示相关赛事或品牌背书。资产、字体和许可证来源统一维护在[第三方说明](../../THIRD-PARTY-NOTICES.md)。

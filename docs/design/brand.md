# 品牌与使用边界

Mizar / Alcor 使用相伴双星的品牌概念：Mizar 对应制播主体，Alcor 对应观察辅助。品牌关联不改变播出画面与观察辅助的数据隔离，也不产生独立界面主题。

## 标志与图标

品牌资产由 `apps/web/public/brand/` 和桌面图标源文件管理。使用已有 Mizar 标志与图标，保持比例、颜色和清晰度，不自行重绘或加入装饰效果。桌面入口、启动入口和产品导航可以展示 Mizar；小尺寸使用已有图标，保留适当留白。实际启动入口和捕获效果由平台验收确认。

产品界面的 Mizar Blue 使用 `accent.primary`，负责交互、选择、焦点与主要操作。Alcor 的辅助品牌色保持次级权重；具体新增数值需要设计变量与视觉审查，不能在页面临时建立调色板，也不承担成功、警告或危险状态。

## 默认播出图形

节目包使用已有彩色标志中的钴蓝 `#3180F3`、冰白 `#E0F2FF`、暖金 `#FFD27A` 与深蓝 `#173A91`。颜色按 `base.color.brand → semantic.brand → broadcast.brand` 管理；不更换产品 UI 的交互色，也不改变 CT/T、赛事身份、队伍身份和目标状态的职责。

主图形是裁出画布的开口弧面，冰白前沿、钴蓝色面与深蓝之间有明确面积层级，偏置的暖金节点只用于少量节目识别。Waiting 可以出现大尺度色面；信息密集的统计页仅在边缘使用低对比材质。Gameplay 读数保持直边，不把比分掏成沙漏，不在每张卡片上重复月牙；Gameplay 的 Mizar Pulse 使用连续深壳与能量边，Focus 和暂停不再依赖弧切；完整规则见 [Mizar Pulse](mizar-pulse.md)。弧面不是重绘后的 Logo，也不是闭环、仪表盘或持续旋转轨道。

展示字采用仓库已有 Barlow Condensed，昵称、队名和中文回退保持清晰的正文字体。通过字体、明暗、平面色块与短时弧形揭示建立亲缘关系，不依赖增加 Mizar 标志面积。

## 品牌动效

相伴、对齐、轨迹可以作为有限的品牌动效，用于品牌入口或明确的状态过渡。常规控件使用共享动效变量，并遵守系统“减少动效”设置。星轨、闪烁、发光不发展成整套主题，不作为普通面板、背景或诊断页面的默认样式。

## 桌面入口与播出画面

桌面入口和产品界面的品牌归 Mizar。播出画面的品牌归赛事：赛事标志、名称、队伍与比赛信息是画面主角，默认节目包在全屏等待、统计和结果页底部使用既有 Mizar 标志作为次级制作署名，赛事名称与标志保持主要层级；Gameplay 不增加品牌遮挡。

Mizar 负责布局、对比度、动效、安全区和渲染质量；赛事提供标志、名称、强调色及可选的轻微视觉处理；队伍提供自己的身份素材。赛事强调色不表示状态，参赛双方配色不替代 CT/T 配色。

播出画面的具体展示字体通过实际视觉稿与渲染对比决定，不在品牌说明中提前固定。Gameplay HUD 同时遵守 ADR-0007。

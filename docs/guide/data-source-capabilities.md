# 数据源与适用范围

Mizar 的基础制播组合是 Windows、CS2 观战客户端与 OBS。游戏进展通过 GSI 进入本地服务，赛事名称、队伍、名单和 BP 来自本地比赛资料或赛事平台。

## 基础能力

| 能力 | 使用条件 | 数据缺失时的表现 |
| --- | --- | --- |
| 比分、回合、选手与当前视角 | 有效的 GSI 数据、身份与地图信息 | 对应项目显示未知或隐藏 |
| 雷达、楼层和道具 | 位置与道具观测、对应地图资源 | 显示数据或地图不可用 |
| 自动节目编排 | 比赛绑定、游戏进展、比赛资料与 OBS 就绪 | 暂停推进并提示处理原因 |
| 队名、队标、赛程与 BP | 本地填写或赛事平台提供 | 按现有资料展示，可逐步补齐 |
| 网站实时状态与公共雷达 | 有效公开数据与已配置的接收端 | 停止发送失效状态，等待有效数据恢复 |
| 精确伤害与击杀事件特效 | 对应的节目事件数据源 | 继续提供基础 GSI HUD |

GSI 通过观战客户端提供基础 HUD 和雷达所需数据，赛事服务器可沿用现有配置。完整官方赛果由赛事资料维护，精确事件特效按数据源提供的字段展示。

赛事方提供 GOTV 连接地址与观战延迟说明，在 CS2 中使用 `connect IP:port` 进入观战。HTTP CSTV 使用专门的广播地址和对应适配器；两类地址按赛事方提供的方式使用。

## C4 爆炸伤害估算

内置资源覆盖 Ancient、Anubis、Cache、Dust II、Inferno、Mirage、Nuke、Overpass、Train、Vertigo。资源版本与许可见[第三方说明](../../THIRD-PARTY-NOTICES.md)。

- 按选手当前位置与站立姿态估算，供观察参考；实际伤害以游戏结算为准。
- 在已下包或拆弹阶段、有效爆炸倒计时最后十秒内展示正值伤害覆盖层。
- 暂停、回合结束、数据过期，或缺少地图、位置、身份和计时数据时隐藏预测。
- 选手血量与死亡状态始终来自游戏数据，地图资源随游戏更新维护。

开关位于 HUD 编辑器的左右选手栏设置中，操作见[HUD 预设与文件分享](quick-start.md#hud-预设与文件分享)。

## 工作台的状态边界

OBS 画面确认定期更新当前场景的缩略图，供导播核对构图与场景。连接、推流、场景对齐和配置分别显示状态；连续画面与声音通过 OBS 预览、录制试听和直播端检查。

B 站状态根据解说资料中的直播间地址查询，分别显示未配置、未开播或无法确认。推流与录制由操作者在 OBS 中启停，观众端体验结合实际画面、声音与网络状态确认。

## 赛事平台

RivalHub 提供现成的比赛资料与实时状态接入。其他平台可按[输入与输出协议](../reference/protocol.md)实现适配。公开输出使用正式节目时间轴，延迟跟随观战数据源。

连接恢复后，Mizar 在身份与地图匹配且数据有效时重新提供现场状态。平台按本场授权、首发、地图和人工接管规则接收，具体恢复语义见[公开实时输出](../reference/protocol.md#公开实时输出)。

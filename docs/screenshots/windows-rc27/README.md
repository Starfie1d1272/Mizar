# RC27 EPL 实机画面

2026-10-08，Falcons 对 Natus Vincere，ESL Pro League Season 24。以下 **31 张图片直接嵌入本页**，来自未经修改的 RC27 与真实 Inferno demo；[来源、环境和 SHA-256](provenance.json)记录实际构建。OBS 节目为 1920×1080，完整桌面为 2560×1440、150% 缩放。

本轮按用户要求在视觉重设计前收尾，不再补齐整个矩阵。图片已由 Agent 查看，未完成最终人工审美确认；Matchup、Nuke 双层、技术暂停及部分边界未覆盖，不作为正式发布通过的声明。工作台保留 RC27 原有说明文案，源码中的简化尚未进入这个构建。C4 与投掷物录像、原始宣传素材保留在本机验收目录；本图集仅收录静态图。

## 来源与验证边界

本地比赛通过真实 Companion 创建接口生成；候选编辑、HUD 保存／应用与地图 BP 使用真实本地接口。HUD 使用仓库 EPL 样例，网站授权与缓存、OBS 状态、MulNX 版本／包列表及部分原生 IPC 为明确模拟。现场游戏为占位，雷达没有实时数据；OBS 缩略图不可用。文件选择器由 Linux Chromium 绘制，不能据此判断 Windows 系统控件语言。

核对页以 2K 浏览器展示同一组件内容；原生窗口本身按屏幕缩放为约 1000×1160，不能把这里的 2K 截图当作原生窗口大小、位置或焦点的实机证据。原生窗口焦点、CS2、OBS 捕获／设备音轨、MulNX 实际运镜与退出恢复仍待 Windows 联合验收。

本地验证：设计检查（含 14 项组件用例）、全仓类型检查、构建、修改范围 ESLint／格式检查通过；7 个定向单元测试文件共 50 项通过；相关浏览器验收共 16 项通过，其中 HUD 保存／应用与异常按钮回归已覆盖本轮修正。既有 PR head 的 CI 成功不作为 rebase 后版本通过的依据。

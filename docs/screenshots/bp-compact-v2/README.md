# 紧凑 BP 视觉 fixture

截图由实际 `BpCompactPresentation` 在 Chromium 生成，背景是仓库 `fixtures/epl-inferno-video/replay/background.mp4` 的一帧，BP 为合成 fixture，FALCONS／NAVI 队标使用仓库现有 fixture 素材，不是 OBS 或赛事实机证据。`seven-mixed` 为 BO3 完成态，`reveal-current` 为进行中，`all-pending` 是直接传入零揭示游标的合成边界测试（正常 session 的非隐藏快照从第一步开始）。BO1／BO3／BO5 各含七个固定卡槽，`missing-long` 使用未知地图和长中文名，`scaled-720` 在浏览器中将 1920×1080 画布等比缩小到 1280×720。

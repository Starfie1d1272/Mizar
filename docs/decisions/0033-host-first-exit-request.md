# ADR-0033：桌面退出请求先恢复游戏再停止服务

状态：Accepted（2026-10-06）。补充 ADR-0027、ADR-0028，替代 CLI 先停止服务再通知 Host 的顺序。

已运行桌面的 `--stop` 通过按包摘要与运行目录隔离的一次性退出请求交给 Host；提交前核对同包本地服务。Host 复用已有退出门禁，先安全切等待场景与释放数据源，再正常关闭受管理 CS2 和恢复视频配置。恢复成功后退出桌面，由外层服务所有者停止 Companion。无桌面的运行仍使用原有令牌与运行身份验证的停止入口。

恢复失败保留 Companion 和 Host，收起现场窗口、打开准备中心并显示明确错误，允许修复后重试；关闭错误提示不代表退出成功。请求只消费一次，不循环弹窗。CLI 有界等待桌面请求句柄与服务均结束，超时返回未完成。直接停止服务等兼容路径已无 HTTP 时不打开拒绝连接的网页，只保留原生恢复与托盘重试。OBS 保持独立运行。

验证分开覆盖请求隔离和单次消费、退出门禁、恢复失败后的实机重试、视频字段恢复及窗口/服务最终清理。

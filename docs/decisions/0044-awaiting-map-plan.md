# ADR-0044：等待地图计划与明确无计划的比赛分开

状态：Accepted

## 决定

补充 ADR-0043：源计划分为 planned、awaiting_plan、unplanned。已有地图时为 planned；赛事比赛尚无地图时为 awaiting_plan；独立比赛尚无地图时为 unplanned。这是当前输入边界的明确判定，不把“暂时没有 BP 数据”当作“不需要 BP”。

awaiting_plan 不从 GSI 创建地图，也不累计胜场。它可以持久化为空检查点，在计划到达且尚未建立执行事实时平滑切换 planned。只有 unplanned 允许按图池与系列规则追加本地观测；完成过的地图不得再占据下一图序，同图重开保留原槽位且不撤销已冻结结果。

## 后果

正式赛事 BP 前的服务器热身不污染地图身份；无 BP 独立比赛继续直接观测。此处不定义训练赛产品的 BP 选择界面或授权；未来支持独立比赛等待 BP 时，应让产品的规则选择显式进入同一个模式判定入口。

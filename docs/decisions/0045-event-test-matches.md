# ADR-0045：赛事测试赛与节目衔接隔离

状态：已接受

## 背景

完整链路演练需要真实赛事授权、名单、双端 BP、游戏数据和网站 LIVE。演示模式不能验证这条链；将测试赛当成普通赛程又会使正式节目的前后场预告引用演练。

## 决定

比赛上下文和赛程摘要携带提供方的 `isTest`，经过解析、本地保存及重载保留。赛事身份与测试用途是两个维度：测试赛继续使用现有事件范围的接入和输出协议，核心状态、身份匹配、BP、地图执行、终局结果与可靠事件保持同一套规则。

赛程相邻关系由原 `deriveScheduleNeighborhood` owner 处理。正式比赛跳过所有测试赛；测试赛只有当前场，不关联相邻节目。制作人员仍可在来源列表明确选择测试赛，阶段及场次标注为测试赛。不增加旧客户端兼容层、另一套遥测链路或测试专用结果 owner。

## 验证

契约回归覆盖提供方解析、持久化往返和混合赛程的双向隔离。RivalHub 验证名单、BP、授权输出与正式统计隔离；Windows / CS2 / OBS 和 B站实际直播、DAK 上传仍需要一次现场演练。

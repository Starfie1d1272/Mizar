# ADR-0032：手动摘要展示与未绑定 demo 的播出投影

状态：Accepted（2026-10-06）。补充 ADR-0017，替代 ADR-0025 中手动半场与结果必须处于对应实时阶段的限制。

手动选择场景是展示控制，不是确认赛果。比赛资料、地图绑定与身份核对通过后，允许手动打开半场、单图结果、图间和整场结果，也允许遥测停止后回看已冻结摘要。缺少摘要时显示等待内容；已确认比分没有选手统计时，显示比分和统计不可用提示。整场尚未完成不能显示已完成标签。自动编排保留阶段、新鲜度、身份与赛果门槛。

Core 为本地 Gameplay 消费面提供独立展示投影。未绑定地图或身份不符的真实 demo 保留游戏观测、CT/T 比分与选手，不带入所选赛事的名称、队标、系列比分和 BP。制作控制和静态摘要继续消费原有比赛事实，后台选择不被清空。

未绑定 demo 的回合历史来自当前规范化观测，复用系列赛已有绝对编号校验；只有连续编号与 CT/T 比分总数一致时才展示。不建立前端历史队列，不补猜加时偏移或官方获胜方。缺少当前证据时保持缺失。

# ADR-0043：冻结地图计划与实际观测记录分离

状态：Accepted

## 决定

SeriesProgress 的 sourcePlan 冻结 planned / unplanned 模式、允许图池与源计划指纹。运行时 maps 是可变观测记录，不能反向定义源计划身份。该决定补充 ADR-0042 的执行、结论与观测边界。

没有计划时，合法图池内的实际地图建立 mapId 为空、selection 为 unknown 的本地记录。追加下一图要求上一图结果已确认且未超过赛制上限；没有阵营身份证据不猜胜者，有计划时不放宽原来的错图及人工绑定规则。运行时记录不代表 RivalHub 已保存 canonical match_maps。

## 后果

检查点升级为 v2，接受空观测并持久化冻结计划，追加地图不导致恢复或资料刷新冲突。不维护旧检查点迁移。图池未知时不能自动追加地图；真实身份匹配、外部在线授权和实机验收仍是独立边界。

# ADR-0018：制作提示与平台直播状态

状态：Accepted

## 决策

Preparation 与 Workspace 复用 Companion 的只读制作提示。比赛与赛果继续由 MatchContext / SeriesProgress 拥有；提示只组织当前任务、结果、下一图和正常业务交接。

图间提醒为 10 分钟软提醒。Companion 在同一比赛、地图执行、来源代际的可信 map_ended 上记录单调时钟；恢复时可用已有地图 completedAt 建立时间锚点。未知结束时间不生成计时。状态最多保留当前比赛一张已结束地图，切换比赛清除。提醒不改变比赛、节目编排或 OBS 操作。

Mizar 与 RivalHub 分别查询 Bilibili。Mizar 的查询 owner 为 Companion，读取已有解说资料中的直播地址，仅接受 Bilibili 的数字房间号，向固定 HTTPS API 发起请求，不跟随重定向。查询超时 4 秒，缓存 30 秒，同一房间合并在途请求，缓存与并发各最多 16 项。多个已配置房间中任一直播即显示正常；无直播但有未知结果时显示「无法确认」。没有已配置房间显示「未设置」。平台查询结果不进入 Program、Runtime 或网站上传契约。

OBS 与 Bilibili 在操作界面分别显示短状态。OBS 正常要求连接、推流、场景对齐和配置检查通过；未知连接不映射成未推流。开播提醒沿用既有解说认领，仅在现场制作且地图正式进行时显示。系列结束继续展示直播事实并提供收尾指引。任何比赛结束或平台失败均不自动开停推流。

图间与系列结束使用固定 RivalHub 官方站点的 HTTPS 比赛工作台链接，仅携带赛事 slug 与比赛 ID。浏览器正常打开链接，Desktop 使用限定站点与路径的系统浏览器命令；不携带凭据或新增自定义协议。比赛与赛后业务留在 RivalHub。

## 验证

覆盖地图结束后继续有遥测、下一图开始、无时间证据、页面重开、换场、缓存和多窗口并发、平台失败、未知 OBS、无人认领以及 HTTPS 链接边界。真实 Windows 窗口和系统浏览器仍需 exact artifact 验收。

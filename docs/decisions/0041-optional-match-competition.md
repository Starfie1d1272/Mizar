# ADR-0041：比赛上下文中的可选赛事

状态：已接受

## 背景

CS 比赛的双方、赛制和执行事实可以先于赛事存在。强制赛事身份会使独立比赛不得不生成占位赛事，并把未预报阵容误当成无效比赛。

## 决定

比赛文档与核心上下文允许空赛事、空阶段和空名单。RivalHub 适配器通过 v2 表达可选赛事，继续严格验证 v1；参赛方标识保持不透明，BP 引用依然必须属于本场双方。本地持久化与节目投影消费相同上下文，不创建第二份比赛状态。

赛程与现有线上输出仍是赛事范围的协议。无赛事上下文不创建赛程、管理链接或 outbound v1 事件；后续独立比赛授权与创建产品另行设计。

## 影响

已有赛事输入、BP 顺序、身份匹配和输出行为保持兼容。空名单只有诊断，不是文档阻断项。无赛事文档需要支持可空上下文的新客户端，不能宣称旧版本可读取；自动化验证不替代 Windows / CS2 / OBS 实机验收。

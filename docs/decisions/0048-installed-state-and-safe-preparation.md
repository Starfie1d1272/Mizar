# ADR-0048：安装版数据目录与安全自动准备

状态：Accepted

## 背景

#194 要求普通用户通过中文安装包进入准备中心，无需先运行 CS2 或手动执行正常配置步骤。沿用 Desktop 的本机操作、Companion 的 OBS 配置以及既有恢复日志，不增加独立初始化系统。

## 决定

- NSIS Setup 使用资格构建的原始便携 payload，额外写入安装标记和卸载入口。安装版将可写状态放在当前用户 LOCALAPPDATA/Mizar；便携版继续使用程序旁 state，显式 MIZAR_STATE_ROOT 优先。卸载只删除安装文件清单，不删除用户数据。
- GSI 自动准备在已有全局操作锁内复用安装事务，只创建不存在且无冲突的文件，或重建与既有所有权摘要完全相同的缺失文件。未知文件、修改过的文件、第三方发送器与模糊安装位置交给显式修复；自动路径不暂停第三方发送器。
- OBS 打开前检查已有进程。首次安全连接可复用现有 reconcile 准备 Mizar 场景；输出中禁止修复。后续重连只检查并沿用现有网页源恢复机制，不重新覆盖操作者改动，不切换当前场景、不控制推流。
- 配置就绪、连接就绪与收到真实游戏数据分别展示。自动准备失败保留诊断与显式修复入口。

## 代价与验收

安装版新增稳定用户目录，便携目录不会自动迁移。Setup 的实际安装、升级、卸载、文件摘要与用户数据保留由 Windows 资格构建验证；NSIS 编译器、脚本和许可证摘要随原产物进入 provenance。浏览器测试不能证明真实 Windows、CS2 与 OBS 制作效果，最终验收仍由 #35 / #90 跟踪。

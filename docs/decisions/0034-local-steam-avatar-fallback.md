# ADR-0034：本机 Steam 头像备用媒体

状态：Accepted（2026-10-06）。扩展开发期素材导入，允许用户配置可选的运行时头像服务。

Companion 按当前选手 Steam64 批量调用 Valve 的 [GetPlayerSummaries](https://partner.steamgames.com/doc/webapi/ISteamUser#GetPlayerSummaries)，只使用头像媒体，不采用 Steam 昵称覆盖赛事或观测身份。赛事提供的头像优先，没有时使用本机缓存。此能力不决定名单、地图绑定、节目门禁或公开赛事事实。

密钥保存在本机运行目录的专用设置文件，读接口只返回是否配置，不回显密钥；密钥不进入比赛文档、预设、采集或支持包。写入口遵守 loopback 与 Origin 校验。网络请求禁止重定向，头像限定已知 Steam HTTPS 媒体域，响应大小、下载并发、缓存数和重试都有上限。失败不阻塞 GSI、节目或启动。

缓存最多保留 256 个身份，七天后可刷新；每次请求最多十人、图片最多两张并行。停用在线获取保留已缓存媒体；清除缓存是单独操作。服务退出取消网络请求。测试覆盖缓存重启、批量、来源限制和密钥不回显；真实网络成功另记实机证据。

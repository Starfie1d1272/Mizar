# ADR-0025：未绑定赛事的 demo 支持手动游戏画面播出

状态：Accepted

## 背景

实机 demo 已有正常 GSI、雷达与选手视角，但当前赛事的地图/身份绑定门槛阻止手动选择“比赛中”。观看任意 demo 测试不应要求先把它登记为正式赛事。

## 决策

新鲜正式输入可手动切换 Gameplay；该动作只切换 OBS 场景并保持人工控制，不建立赛事绑定、阵营映射、官方身份或结果。画面继续消费现有 Program 投影及其 observed / canonical / unavailable 语义，缺失信息保持缺失。

自动编排、对阵、半场与结果画面继续要求各自可信证据；缺失或过期遥测不能通过手动 Gameplay 门槛。独立 demo 不自动推进已选择赛事，也不修改官方赛果。使用“恢复自动”仍受严格绑定门槛约束。

## 验证

控制器覆盖 fresh + 无绑定/身份冲突的手动切换、过期拒绝、结果门禁及切换中断回滚；Director 覆盖自动门禁。RC 的真实 demo/OBS 与重启布局证据单独记录。

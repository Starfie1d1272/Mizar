# ADR-0042：执行结束、确认结果与地图观测分离

状态：已接受

## 决定

比赛执行可以已经结束，但结果待补、明确不提交，或只有确认总比分。地图观测不必完整，不能用缺少地图推断比赛尚未开始。

SeriesProgress 保留地图观测和胜场；比赛文档保留上游结论及执行结束时间。终局投影采用已确认结果或空比分，进行中的比分继续取观测进度。确认总比分必须符合赛制，非弃赛结果不得违背已知单图和完成顺序。pending 与 omitted 跨存储、传输和投影保留，观众只看到简洁的结束状态与可用比分。

## 后果

只有 2:1 总比分时仍可投影已结束，且不制造地图记录；无结果结束显示空比分。补录或更正刷新结论，不重写观测计数器和执行结束时间。当前 Mizar 同步升级相关契约及消费者，不维护旧版本读写适配。现有 RivalHub 赛事输入与实时身份、授权边界不变。

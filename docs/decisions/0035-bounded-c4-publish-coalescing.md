# ADR-0035：C4 预测的批量完成与有界发布合并

状态：Accepted（2026-10-07）。补充 ADR-0029，替代每个选手单独往返与每次等待立即发布的调度；预测资格、模型、缓存键和公开协议不变。

## 决定与理由

RC14 反馈表明异步预测在输入不断变化时频繁呈现等待与估算，短暂闪现削弱可读性。Companion 将同一地图与上下文内、同一投影的预测合并为一次 Worker 消息，仍最多十个在途选手输入；完成时先写入整批缓存，再通知当前状态重新投影。

普通实战帧仅因精确输入预测未完成时，完整投影的发布可合并最多十六毫秒。保留的是已发布快照及其原游标，不把旧估算写入新帧。固定期限不因新输入而延长；计算完成重新读取唯一当前运行时，慢计算到期则发布当前等待状态。

首次发布、遥测失效、身份或上下文状态变更、生产者/会话/代际/地图切换、回合或比分变更、目标状态变更，以及非预测等待的资格失败不合并。过期截止仍独立运行；关闭取消发布计时器。Program、雷达及其它随批投影仍属于同一发布批次。

代价是普通帧最多增加十六毫秒发布延迟，换来小于一显示帧的计算空档不反复切换估算。主线程不等待 Worker，接收、归约与内部当前投影照常更新。离散重放仍显式排空当前输入并重投影，不能用现场合并代替确定性等待。

自动化覆盖批量计算、精确输入、旧上下文丢弃、慢计算期限与边界立即失效；实际 Windows/OBS 闪现及 HUD 延迟仍在新候选包上测量。

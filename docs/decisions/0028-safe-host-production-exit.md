# ADR-0028：Host 正常退出复用安全制作收尾

状态：Accepted（2026-10-06，RC9 复核收尾）。

## 决定

补充 ADR-0027。托盘「退出 Mizar」与「退出工作台」调用同一个 Companion 制作事务，先切到安全等待、释放数据源，再关闭本次受管理 CS2 与恢复配置。Host 通过固定回环地址调用既有带修订号的制作控制接口，新增 `shutdown` 动作在成功收尾后阻止新进入；已处于准备状态且场景为等待时不要求连接 OBS，但仍释放数据源。Host 不复制场景或比赛状态。

Host 在退出开始即关闭启动与窗口进入闸门，再在后台取得游戏操作锁，等待已经接受的启动完成；长操作不阻塞界面。退出期间拒绝排队的新启动。失败保留 Host、游戏未完成恢复记录与原生错误提示，允许重试退出；已成功收尾后游戏恢复失败的重试不重新进入制作。普通退出只有所有步骤完成后才停止 Companion。

非零退出码的启动失败、系统强制终止属于异常路径；不伪装成安全制作收尾，未完成的配置备份沿用持久恢复机制。

## 验证范围

Companion 回归覆盖安全切场失败、释放失败、准备态退出及成功后的进入拒绝；Host 回归覆盖顺序、失败不关闭游戏、启动闸门与重试。真实 OBS 切场、Windows 游戏退出写盘与配置恢复仍须在固定 RC9 包验证。

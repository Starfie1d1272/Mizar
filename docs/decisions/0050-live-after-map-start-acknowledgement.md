# ADR-0050：实时快照等待地图开始回执

状态：Accepted

## 决策

补充 ADR-0021 的投递顺序：RivalHub 连接适配器在当前数据源认领对象内，记录最近一次成功投递的 `map_started` 执行游标。只有生产实例、会话、数据源代际与地图执行均匹配，才发送实时快照。每次重新认领重新等待；旧请求晚完成不能授权新认领。结束阶段沿用同一执行的开始回执，不以结束事件重新取得资格。

此记录只拥有传输先后关系，不进入 Core、检查点或公开协议，不恢复比赛事实，也不替代网站校验。可靠队列与重试继续由既有 outbox 负责；等待时丢弃实时快照，成功后发送当时的最新状态。

## 原因与边界

网站认领响应仅建立数据源会话，身份与执行证据由可靠开始事件建立。两条上传通道无顺序时，热身或开局快照可能先到，被网站拒绝后又被客户端解释为权限丢失，反过来阻止开始事件投递。

真实的上传权限拒绝仍停止该认领；旧认领请求的拒绝不得清除并发建立的新认领。开始事件的成功 HTTP 回执只允许尝试发送快照，网站继续决定是否采纳，不能把它当成官方比赛已开局或赛果确认。

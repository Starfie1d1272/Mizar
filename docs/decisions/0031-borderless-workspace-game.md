# ADR-0031：工作台中的受管理 CS2 使用无边框窗口

状态：Accepted

## 背景与决定

RC12 实机反馈三个区域出现白边及间隙。CS2 采用带原生边框的窗口，Host 以整个原生外框避让面板；不可见的调整尺寸边界也被计入，且缩窄左栏后底栏旁边出现未覆盖区域。

本次受管理 Steam 启动改为 `-windowed -noborder`，视频事务将已有白名单 `setting.nowindowborder` 设为 `1`，仍保持 `fullscreen=0`。Host 同时移除已跟踪游戏的 caption/thick-frame 样式，并用 DWM 窗口属性关闭游戏与三个现场窗口的系统描边、圆角。这让游戏客户区与无边框窗口外沿一致，沿用原有 75% 上限、16:9 客户区和三个窗口平铺。保留外框避让作为系统或游戏未接受设置时的退路，不把退路视为无缝验收通过。

游戏原始窗口样式、DWM 圆角和边框属性由 Host 保存，更换游戏句柄及正常释放跟踪器时恢复；恢复前核对原 PID，已关闭或被复用的窗口不处理。不修改系统全局主题或窗口偏好。原生窗口样式仅在该游戏进程生命周期内存在；视频设置仍走持久恢复事务。

本决策补充 ADR-0030 的边界布局，替代 ADR-0026 的默认带边框窗口配置；原有视频备份、身份核对、退出恢复和临时启动项边界保持。退出恢复原 `nowindowborder` 值，不修改持久 Steam 启动项、键位或 autoexec。

自动化验证无边框字段参与原有完整恢复事务；指定版本实机确认客户区、外框与面板连续且没有白边、HUD 对齐、OBS 捕获及退出配置恢复。游戏拒绝启动项或重写窗口模式时保留实际限制，不能仅凭参数存在认定通过。

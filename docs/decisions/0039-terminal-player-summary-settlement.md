# ADR-0039：同一地图结束执行的选手摘要收敛

状态：Accepted（2026-10-07）。补充 ADR-0017 的当帧选手摘要规则，不改变系列赛已确认比分与回合历史的冻结。

RC21 实际 Nuke demo 在首个 gameover 观测已经提供最终 13:5 和 18 回合历史，但 C4 爆炸造成的死亡仍在随后观测中更新。只保存第一帧 K/A/D 会使结果页少计末局死亡。

地图结束仍同步捕获有限摘要。只有同一生产实例、直播会话、来源代际、地图执行与地图名称，严格更新的接收序号、新鲜遥测、可信身份及已绑定系列赛，才可继续消费 gameover 的直接 K/A/D 观测。比分必须与捕获值相同，两边选手身份集合必须分别完整一致。只更新对应选手的 K/A/D；缺失字段保留原值，名字、头像、比分和历史不被重写。摘要游标记录最后一次实际统计更新，没有变化不更新。

换执行、换来源、名单变化、身份不符或遥测过期不更新既有摘要；下一图和之后的元数据不能回写上一图。保留最多五图与换比赛清除规则，不增加计时器、推断死亡、前端累计或第二套赛果状态。

回归覆盖延迟死亡、不同执行/来源/生产实例、旧序号、名单变化、过期与身份不符、比分变化，以及原有跨图保留和换比赛清除。实机结果继续记录在 #35，RC21 的首图失败证据与新包验证分开归属。

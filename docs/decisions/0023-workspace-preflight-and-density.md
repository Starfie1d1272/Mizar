# ADR-0023：现场工作台准备检查与固定布局

状态：Accepted

## 背景

Windows RC4 的工作台将雷达空数据渲染为透明画布，制作与配置混在可滚动底栏中。OBS 进程已经打开也可能没有控制连接，首次使用者缺少必要连接引导。

## 决策

- 现场页面固定布局且禁止滚动，常驻场景与操作按钮全部可见。设置、完整比赛资料、任务与诊断复用既有独立页面；不建立新主题或第二份业务状态。
- 雷达无有效数据时使用明确占位；已知当前或计划地图可显示底图，标注等待状态。仅为展示回退，不构造 RadarFrame 或补造玩家位置。
- 进入或恢复现场的产品入口读取当前 OBS WebSocket 状态与场景检查结果。未连接或仍有配置问题时先打开 OBS 引导，不提交 enter 命令。连接设置不折叠为高级功能。
- Companion 仍拥有唯一制作生命周期和 OBS adapter；正式控制接口语义不变。已经进入的现场遇到 OBS 断开，仍可保留本地制作和恢复能力，不强制退出。
- Host 保留显示器工作区和独立窗口布局，关闭左栏、底栏、本机 HUD 的原生阴影；不占用系统任务栏。

## 与既有决定的关系

ADR-0010 中允许 OBS 离线时直接从产品入口进入现场的部分由本决策替代。其运行中离线恢复、窗口承载、事实归属与 OBS 管理边界继续有效；ADR-0022 的允许远程捕获策略继续有效。

## 代价与验证

初次进入需要完成 OBS 连接；减少现场常驻内容意味着完整说明通过对应工具查看。检查期间的网络失败保留准备状态，连接成功后重新进入。布局自动化验证常见分辨率/缩放下的滚动尺寸、控件边界和最小点击区域，Windows 阴影与 DPI 实测不能由浏览器截图替代。

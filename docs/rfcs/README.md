# 研究提案

RFC 保存尚需验证、存在重要替代方案的设计。它说明问题、依据、候选方案、失败处理、验证方法与未决问题，不表示当前已实现。

- [RFC-0001：较早时间轴与观察辅助](0001-lookahead-observer.md)：研发方向，非当前产品交付承诺。
- [RFC-0002：受管理的 CS2 转播配置](0002-managed-cs2-config.md)：启动预设、玩家配置备份与退出恢复，Draft 研究，尚未实现。

状态可为 Draft、In Review、Accepted、Rejected、Superseded。接受研究方向不等于承诺所有增强功能；改变已接受架构时仍需按 [ADR 规则](../decisions/README.md)记录。实现已吸收的部分收敛为指向当前规范的链接，短期进度留在 Issue / PR。

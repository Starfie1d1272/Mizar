# Windows 便携版快速开始与故障排查

## 第一次使用

1. 把完整 ZIP 解压到自己可写的目录，不要在压缩包内直接运行，也不要把运行资料放进 `resources`。电脑需要 Microsoft Edge WebView2 Evergreen Runtime；包内已带 Node，不需要安装开发工具。
2. 双击 `Mizar.exe`，首先进入准备中心。关闭窗口通常只是隐藏；托盘可重新打开。托盘不可用时，主窗口标题会说明关闭窗口将退出。
3. 打开「设置 → CS2 与 GSI」，点击「自动检测 CS2」，再「安装 / 修复 GSI」。无法唯一发现安装目录时使用「选择 CS2 安装目录」。安装后重启 CS2。
4. 在「设置 → OBS」打开 OBS、检查配置并修复 Mizar 场景；需要时输入 OBS WebSocket 密码。正在推流或录制时，先停止输出再修复场景集合。Mizar 不替你配置平台推流密钥。
5. 在「比赛」创建或选择本地比赛；连接 RivalHub 时先在设置授权，再选择已有赛程。本地比赛可从双方队名和 BO 格式开始，之后补资料与 BP。
6. 在准备中心打开「节目预览」，确认双方、地图和画面；预览本身不会切换 OBS 正式场景。HUD 与 BP 工作台按需打开。
7. 准备完成后「进入现场」，Workspace 与本机覆盖才围绕 CS2 展开。「隐藏现场」保留当前制作；「结束制作」回到准备状态。OBS 推流的启停由操作者确认。
8. 不再使用 Mizar GSI 时，在设置点击「恢复原 GSI 配置」。结束使用时从托盘选择「退出 Mizar」，明确停止本地服务；托盘不可用时按标题提示关闭主窗口退出。

## HUD 预设与文件分享

在准备中心「画面」点击「打开 HUD 编辑器」；浏览器备用入口为 `http://127.0.0.1:3000/operator/hud`。

1. 在「预设」选择 Mizar 默认、类 EWC、类 IEM 或类 Perfect World 预设，检查预览；内置资源只读，调整后使用「另存为」创建自己的副本。
2. 「配置组件」用于调整呈现方案与内容开关；「布局」用于调整位置、显隐和雷达尺寸。编辑器的样例或重放只用于预览，不能当作当前比赛的数据。
3. 保存或另存修改过的资源；如果另存了布局，在预设中选择该布局并保存预设。当前预览与预设引用必须一致。
4. 确认后点击「启用当前预设」，检查「当前启用」和实际节目。**选择、编辑、保存、另存和导入均不改变正式节目，启用才会上屏。** 已启用配置在服务重启后恢复；之后只保存编辑也不会刷新已启用的内容，需要再次启用。

分享前保存或放弃所有未保存修改。在「预设」点击「导出预设文件」，确认下载的 `.mizar-hud.json`；接收方点击「导入预设文件」，选择文件，再从预设列表选择新副本、预览并启用。

文件包含组件设置、布局和受控外观，不包含比赛资料、实时数据、启用状态、图片素材或执行代码。文件按当前格式校验，UTF-8 大小最多 256 KiB；只接受已支持的组件方案、外观和一致的资源引用。导入创建新的预设、布局和外观副本，不覆盖已有资源，也不自动启用。格式错误或版本不支持时修正文件后重试，失败不会留下部分副本。

导入／导出按钮不可用时，先处理未保存更改，确认配置连接正常；导出还要求当前预览布局与预设引用一致。多个窗口同时编辑产生冲突时，保留需要的修改，再按提示重新读取或放弃；不要反复保存覆盖另一窗口的新内容。当前不提供社区分发平台或任意代码插件安装。

## C4 爆炸伤害预测

「配置组件」选择左侧或右侧选手栏，使用「C4 伤害预测」开关；两侧分别设置，内置预设默认开启。修改后保存／另存预设并启用，才能改变正式画面。

- 资源随固定版本 `cs2-c4-damage@0.1.0` 提供，覆盖 Ancient、Anubis、Cache、Dust II、Inferno、Mirage、Nuke、Overpass、Train、Vertigo。使用这些资源无需自行提取游戏文件、准备地图文件或额外联网下载。
- 预测表示“如果现在爆炸，按当前位置与站立姿态估算的伤害”，不表示系统观测到了选手的真实姿态。真实 HP 与死亡状态保持不变，不提供站／蹲双值，也不保证必死、必活或全地图实机精确。
- 覆盖层只在已下包／拆弹、爆炸倒计时大于零且剩余不超过十秒时显示。暂停、回合结束、断流、缺少有效倒计时或预测输入时隐藏；伤害为零也不绘制伤害覆盖层。C4 状态图标和伤害覆盖层是两种展示，看到图标不代表预测必须显示。
- 未支持地图、资源缺失／损坏、检测到的模型／资源／地图不一致，以及位置、朝向、身份或数据新鲜度不足时安全隐藏。先确认当前地图、有效比赛数据和已启用预设的开关；资源问题重新解压完整产品包后重试，持续异常时导出诊断包。不要用旧地图文件强行替换。

十图资源随包和内部校验通过，分别证明资源交付与自洽；它们不等于真实 CS2 精度验证，也不保证未来游戏更新的兼容性。

## 节目编排与现场控制

进入现场后默认「自动编排」，根据有效比赛数据推进赛前等待、对阵、BP、比赛中、半场、单图结果、图间与整场结果。数据不足、过期、身份冲突、暂停或 OBS 切换失败时可能显示「自动暂停」和原因；先处理提示，再「恢复自动」。系统不靠猜测补出缺失赛果。

在现场底栏点击「手动切换」并选择场景后进入「手动保持」，直到显式「恢复自动」。打开手动场景列表本身不会接管。节目预览仅用于核对展示，不触发正式切场；其中「连续演示」使用展示样例，不证明真实自动编排已通过。

BP 在「节目预览」的 BP 工作台核对、填写、播放和收起；本地比赛可先创建，再补 BP。浏览器入口为 `http://127.0.0.1:3000/preview?scene=bp`；旧 `/operator/bp` 会转到该入口。准备阶段可手动预览 BP；现场自动编排会按有效比赛状态准备和播放，资料不全时先处理工作台提示。

「隐藏现场」保留本次制作；「恢复现场」回到同一现场。「结束制作」尝试切到安全等待画面并释放当前数据源，成功后回准备状态；失败时按提示修复后重试。结束制作不会删除赛事资料，也不代替 OBS 的停止推流／录制。完全停止 Mizar 使用托盘「退出 Mizar」。

「画面」中的本机覆盖显隐只影响自己 CS2 上方的覆盖，不改变 OBS 节目。需要改变正式 HUD 时使用预设启用操作；私有 Workspace 与未来观察辅助不能作为正式画面采集。

## 出现问题时

- **窗口打不开**：查看原生错误提示及其「打开日志目录」。若明确提示 WebView2 不可用，安装或修复 Evergreen Runtime 后重试；其它错误不据此归因。重新解压完整包可排除资源缺损。
- **准备界面打不开，但本地服务仍正常**：浏览器访问 `http://127.0.0.1:3000/debug`，从同一诊断页导出。若服务也未启动，先按原生错误恢复；本机 `state/logs` 保留原始失败，不需要反复删 state。
- **数据不更新**：先在设置核对 GSI 安装与冲突，重启 CS2；诊断页的「数据过期」仅表示暂未收到有效数据，不证明游戏已退出。
- **OBS 没画面**：核对连接、场景和检查结果；修复只管理 Mizar 场景，当前输出期间不会重建场景集合。
- **预设没有上屏**：检查「当前启用」，确认已保存并「启用当前预设」；样例预览与本机覆盖显隐不改变正式节目。
- **C4 预测不显示**：按上节检查已启用开关、倒计时窗口、地图与数据；正常隐藏不等于 C4 图标或 GSI 必然故障。
- **场景不再自动切换**：检查是否「手动保持」或「自动暂停」，处理提示后「恢复自动」。
- **重启后需要恢复**：保留 `state`，先确认比赛资料与已启用预设，再核对 CS2/GSI 和 OBS；不要把删除 `state` 当成常规修复。切换产品包时保留旧包和旧数据备份，版本格式不兼容时按对应发行说明处理。
- **端口占用**：停止占用 3000 端口的程序；Mizar 不会静默换端口。关闭浏览器不会停止 Companion。

## 导出诊断包

进入「设置 → 高级 → 运行诊断 / 导出诊断包」，点击「导出诊断包」。桌面弹出原生另存为窗口，选择可写目录保存 `.json`；取消可以重试。浏览器备用入口会发起普通下载，请在下载列表确认文件。

诊断包包含构建 SHA、产品包摘要（开发环境可能不可用）、运行版本、安全状态、最近启动事件和日志截断说明。GSI/CS2 探测两秒内未回应时仍会生成诊断包，对应状态明确不可用。Host、supervisor 与 Companion 的启动会话通过包内关联键对照；每次重新导出会更换关联键。

日志摘要会保留失败阶段与可识别的数值错误码，舍弃自由文本错误、主机名、路径、网络地址、选手身份和凭据。完整原始错误仍在本机，不能把摘要当成完整日志。文件最多 256 KiB；不会导出原始 GSI、比赛库、capture 或整个 state。日志文件缺失/不可读、未知记录、历史截断在文件中明确标出，导出不删除原记录。

导出失败时检查本地服务和保存位置后重试。可以把生成的 JSON 附在 GitHub Issue 中，并补充当时操作与期望结果。支持入口为 [GitHub Issues](https://github.com/Starfie1d1272/Mizar/issues)；至少写明产品版本／构建 SHA、发生时间、复现步骤、实际结果和期望结果。截图先遮盖私人资料；服务无法启动时注明无法导出，保留本机日志供进一步定位。不要直接上传 `state/` 或原始日志；其中可能含本机路径、凭据或其它私有资料。

默认日志在 `state/logs`；设置过 `MIZAR_STATE_ROOT` 时使用该目录。原始日志保留当前及最近三份历史文件；重复尝试不会立即抹去上一失败。完整内容/限额/安全边界见 [ADR-0016](decisions/0016-bounded-support-export.md)。上述路径与自动化测试不替代真实 Windows + CS2 + OBS 验收。

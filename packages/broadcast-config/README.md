# 播出配置合同

本包定义本机可编辑模块、完整播出方案与持久活动快照。资源版本由各 provider 拥有；配置仅保存精确引用。音乐和运镜模块包含自动策略，本机音量、监听、设备凭据、人工接管和播放游标不在合同内。

`parseBroadcastConfigDocument` 校验配置文档及完整绑定；第三方 HUD 的 panel 值还须由对应已安装资源的 profile 校验。`clonePreset` 检查方案及每个引用模块的修订，复制所有可编辑模块并重写原生 HUD 的内部 ID，素材引用保持共享。`preparePreset` 不修改文档或操作设备；调用者必须在生产生命周期与资源引用提交的守卫内完成解析、复查和持久化。预览仅使用准备结果，不提交活动快照。

运镜源的树摘要和转换器版本用于判断有效内容，`acquisition` 记录取得来源；发行版变化本身不推进运镜活动修订。开发测试来源必须显式标识。资源可用性、兼容能力以及具体源内容验证由领域 provider 完成。

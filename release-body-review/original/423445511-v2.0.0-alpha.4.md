### 启动、连接与诊断

- 修复早源观察器首次启动时输出父目录缺失导致的失败；诊断保留每次启动的阶段、终态和关联编号，便于从支持包定位问题。
- 标准模式保持一键启动进入工作台；MulNX 自动启动仅适用于支持启动协议 1 的官方版本。GoTV 地址改为进入后的「本图连接」确认；换图时保留工作台、OBS 与 CS2，清理旧早源和提示，再确认新图连接。保存偏好不重新连接节目。
- 连接输入支持两种常见的 connect/password 顺序、引号与尾部分号，并拒绝重复命令、注入、无效端口及带前导零的 IPv4 分段。
- 修复赛前核对窗口关闭权限，并补齐从工作台打开音乐与运镜设置的入口。
- MulNX 当前版本不支持自动启动时，提示前往官方手动启动与游戏交接入口；停止控制请求提交或结果未知后，对同一游戏实例不再重发，刷新或重启 Mizar 也保留保护。结果未知时先在游戏内核对，需要继续控制时正常重启游戏。

### 私有观察提示

- 私有击杀提示按配置的节目与早源延迟差直接估算，延迟校准仅作参考，不再作为显示门槛；新安装默认延迟差 120 秒、提前 5 秒，已保存设置保留原值。
- 新事件靠近雷达，提示按剩余时间降序排列；暂停、换图、来源切换及已发生事件继续清理旧提示，私有信息不进入播出画面。
- 支持包补充提示接收、过滤、等待、阻塞、来源健康和重置摘要，便于定位长时间等待问题。

### 比赛列表

- RivalHub 比赛库优先展示进行中的比赛，其余未结束比赛按开赛时间排列，已结束及已取消比赛归后；刷新后保留仍存在的手动选择。

### 音乐试听

- 音乐设置可通过 OBS 试听未保存的音量与选段，试听最长 15 秒；保存仍为独立操作。正式音乐占用时提示先停止，推流、录制或状态未知时需明确确认。
- 切换曲目、离开页面与正式音乐接续时清理试听；OBS 断连时提示停止尚未确认，重连后优先清理。试听不改正式播放进度或人工停止状态。

### 使用与已知限制

- 本版仍为内容联调预发布，保持现有默认 MulNX 启动偏好，已有配置保留原选择；官方启动器的环境检查及控制能力要求继续适用。
- 官方 MulNX Beta16.2 尚不支持启动协议 1，请通过官方启动器手动启动并完成环境检查，再从现有「MulNX 游戏交接」入口明确借用游戏。Beta16.2 的 `System/Stop` 仅卸载组件，不退出 CS2；已有 MulNX 安装不会自动升级，旧版用户需先退出游戏，再显式更新 MulNX 才能获得该能力。
- 从本版本 GitHub Release 手动下载完整 Setup 或离线 ZIP；稳定更新器不提供预发布，Box 不同步本版。安装版沿用现有安装及资料位置，不承诺与稳定版并存；升级或回退前备份资料并正常退出 Mizar。

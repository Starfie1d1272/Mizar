### 启动与本图连接

- 新安装默认使用「标准启动（Mizar 管理）」，沿用 Steam 启动 CS2 后打开直播工作台，再通过「本图连接」确认地址；升级保留已保存的标准或 MulNX 启动选择。
- 工作台支持先启动游戏、稍后确认本图地址；换图保留工作台、OBS 与 CS2，清理旧早源和提示后确认新图连接。保存偏好不重复连接节目。
- 连接输入支持常见的 connect/password 顺序、引号与尾部分号，并拒绝重复命令、注入、无效端口及带前导零的 IPv4 分段。
- 保留 MulNX 官方手动启动、游戏交接与已有运镜能力。自动启动仅适用于支持启动协议 1 的官方版本；当前安装版本不支持时，按提示完成官方环境检查并手动启动，再明确借用游戏。停止控制提交或结果未知后，同一游戏实例不再重复发送；需要继续控制时先核对游戏并正常重启。
- 修复赛前核对窗口关闭权限，补齐工作台中的音乐与运镜设置入口。

### 私有观察提示与诊断

- 工作台提供私有击杀提示，按设置的节目与早源延迟差估算提示时间，后台延迟测量仅作参考。新安装默认延迟差 120 秒、提前 5 秒；已保存设置保留原值。
- 提示靠近雷达，按剩余时间降序排列；暂停、换图、来源切换及已发生事件继续清理旧提示，私有信息不进入播出画面。
- 修复早源观察器首次启动时输出目录缺失导致的失败；支持包补充启动阶段、操作关联、提示接收与过滤、阻塞和来源健康记录，便于定位问题。

### RivalHub 比赛库

- 配对后的周期刷新只读取轻量赛程，不再逐场预取全部比赛详情。打开详情时按需读取该场，浏览期间定期刷新；制作本场继续自动刷新，激活前重新核对网站最新资料。
- 显示授权账号；本人认领的未结束比赛置顶，已结束和已取消比赛仍归后。账号和认领标记依赖网站提供对应字段，旧网站缺字段时保持未知，不按昵称猜测身份。
- 保留已浏览详情的离线缓存；未浏览比赛不再保证离线详情可用。网站暂时不可用或限制读取时保留当前制作与已缓存资料，并按退避期限重试。

### 音乐试听

- 音乐设置可通过 OBS 试听未保存的音量与选段，最长 15 秒；保存仍为独立操作。正式音乐占用时提示先停止，推流、录制或状态未知时需明确确认。
- 切换曲目、离开页面与正式音乐接续时清理试听；OBS 断连时提示停止尚未确认，重连后优先清理。试听不改正式音乐进度或人工停止状态。

### 升级

- 稳定版 1.6.0 及以后可通过应用更新检查 1.7.0；更早版本请手动安装。升级前备份资料、结束制作并正常退出 Mizar。
- `2.0.0-alpha.4` 不会自动降至 1.7.0。请先备份资料、正常退出 Mizar，再从本版 GitHub Release 手动下载完整 Setup 或离线 ZIP；安装版沿用现有安装和资料位置，不承诺与稳定版并存。

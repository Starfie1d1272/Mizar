### 运镜

- 支持通过 MulNX 加载 Demo 后直接试播运镜，无需创建测试赛或选择正式比赛；结束后保留游戏运行。
- 回合开场运镜可从冻结时间延续到选手出门。

### 制作

- 整理本场、比赛库、HUD 与设置流程，优化 16:9 桌面布局。
- 完善旧备份选择与按字段恢复，保留当前资料和游戏配置。

### 诊断

- 保留带时间的 CS2 控制台警告，以及检查点、HUD、头像和 RivalHub 配置读取失败的原因。

### 使用

本版用于 Windows 运镜与 Demo 试用，请从 GitHub 下载完整安装包或 ZIP。安装版沿用现有资料位置，升级前请备份。内置 MulNX 与运镜资源，MulNX 可独立检查更新。完成本机彩排后再用于比赛。

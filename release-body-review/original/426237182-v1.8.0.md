### 声音与音乐

- 「设置 → 声音」集中管理游戏、其他解说、麦克风和音乐四路音量及静音；音源、音乐和场景策略分开设置，切换时保留音乐草稿。单曲可设置音量，也可恢复跟随场景默认值。
- OBS 场景可自动识别唯一的 TeamSpeak 窗口并准备独立音频来源；也可选择其他应用或绑定已有 OBS 音源。自定义配置、输出中和无法确认的情况保留提示，需在 OBS 核对音轨及重复采集。
- 中场可选择保持、降低或静音游戏音源；比赛恢复及人工接管后的处理在设置中说明。音乐支持选择已保存曲目播放、暂停、继续、停止、拖动进度和恢复自动；本机监听在 OBS 所在机器生效，注意桌面采集可能回灌。
- 「导入音乐包」提供 Box 下载入口，下载后通过现有 ZIP 导入。请核对各音乐包的来源、许可和署名要求，下载入口不授予音频使用许可。

### BP 与播出画面

- OBS 设置可选择全屏 BP 或游戏画面加透明 BP 底栏，手动和自动播出共用选择。无法确认受管游戏画面时回退全屏并提示；自定义场景也可使用透明浏览器源。
- 优化 HUD 烟雾、连续伤害和 C4 状态反馈；设置与核对窗口在较窄窗口中改善排列和滚动，保留原有工作台布局。

### 游戏配置与私有提示

- 统一解说 CFG 默认启用，覆盖标准、Demo 和 MulNX 启动路径；数字 1–9 和 0 选择观战槽位，H 键切换原生 HUD。键位身份有歧义时保留原设置，退出时保护人工改动和恢复备份。
- 私有击杀提示使用节目和早源的匹配证据校准实际延迟，断流或连续性无法确认时暂停并重新校准；工作台显示校准状态。提示仍可能受匹配歧义和画面延迟影响，不进入公开播出。
- MulNX 自动启动仍依赖支持启动协议的官方版本；当前不支持时按提示通过官方入口手动启动和交接。

### 比赛资料

- 地图结束时可独立发送最后有效的选手击杀、死亡和助攻快照；旧网站拒绝新事件时不影响既有比分和后续地图。网站接收及展示取决于配套版本的上线情况。

### 升级与使用

- 升级前备份资料、结束制作并正常退出 Mizar。稳定版 1.6.0 及以后可通过应用更新检查；更早版本请手动安装。便携版从正式发布页下载并保留原用户数据目录。
- 真实 Windows、CS2、OBS 音画、按键恢复和运镜仍需按现场环境核对；自动化验证不能代替实机验收。

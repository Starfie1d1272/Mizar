- 本版供音乐和运镜内容联调。音乐可直接导入试用；推荐运镜包及配套内容仍待提供，实际镜头与音画同步需现场确认。

- 当前请手动启动官方 MulNX 并通过其环境检查；已有外部游戏在设置中的「MulNX 游戏交接」检查并明确借用，或使用 Demo 运镜试播入口。进入后重新连接并确认游戏内已载入隔离运镜包，再人工试播；退出工作台保留外部游戏，由操作者从官方入口退出。

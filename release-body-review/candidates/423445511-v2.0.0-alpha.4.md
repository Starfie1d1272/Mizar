### 新增功能

- 音乐设置支持通过 OBS 试听未保存的音量和选段，每次最长 15 秒。

### 体验改进

- GoTV 地址改为进入工作台后的“本图连接”填写，换图保留工作台、CS2 与 OBS。
- 私有击杀提示按设置的延迟差估算，新安装默认延迟差 120 秒、提前 5 秒；已保存设置保持不变。
- 比赛库优先显示进行中的比赛，其余未结束比赛按开赛时间排列。
- 工作台补充音乐和运镜设置入口。

### 问题修复

- 修复提前提示首次启动时因目录缺失而失败，以及赛前核对窗口无法关闭的问题。

### 升级提醒

- 本版需从 GitHub 手动安装，升级或回退前备份资料。
- 当时的 MulNX Beta16.2 需通过官方启动器手动启动，再从 Mizar 交接游戏；“停止控制”保留 CS2。停止结果待确认时请在游戏内核对，继续使用控制功能前正常重启游戏。

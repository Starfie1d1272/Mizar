### 当时的发行记录（含旧版变更，待去重审查）

用于继续验证首次启动与 #35 Windows + CS2 + OBS 制播流程的 RC1，应用版本 `1.0.0-rc.1`。

下载 **Mizar-RC1-win-x64-portable-7696815.zip**，完整解压到新的可写目录，等待解压完成后运行 `Mizar.exe`。无需安装 Node 或 pnpm；需要 Windows WebView2 Runtime。`evidence.zip` 供维护者核查，用户无需下载。

本次修复：

- RC0 在校验全部程序文件期间，桌面会在 35 秒后误报制播服务超时。RC1 为文件校验和服务就绪设置独立期限，校验进度进入日志。
- 文件校验改为最多 8 个文件并发读取，保留全部文件 SHA256 和内容摘要验证。
- 去掉运行时不需要的 npm、Corepack、类型声明、源码映射和构建缓存，减少首次启动的文件读取。
- 缺失文件及校验超时显示具体阶段和诊断，避免全部归为服务启动失败。
- Windows 自动化通过资源管理器 ZIP 处理器解压最终发布包，再校验资源、服务启动、GUI 与退出。

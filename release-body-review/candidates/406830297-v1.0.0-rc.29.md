### 当时的发行记录（含旧版变更，待去重审查）

RC29 修复了 RC28 在部分 Windows 环境首页误报找不到 CS2 的回归，并补齐后台配置失败的诊断记录。

- 修复 Windows 逐字路径前缀传入 PowerShell 5.1 后导致脚本初始化失败的问题，恢复 Steam / CS2 安装检测。
- GSI 与受管理 CS2 的后台脚本统一记录原始异常、stderr、退出码、超时及解析失败；日志保存到 `state/logs/desktop.ndjson`，凭据脱敏，超长输出明确标注截断。
- 公共脚本初始化失败也保留最初异常，避免错误处理再次失败掩盖根因。界面提示具体操作、失败阶段及日志位置。
- 高级设置的“诊断与支持”提供 GitHub 问题反馈入口，支持包保留安全错误摘要。
- 操作手册、诊断说明及缺陷报告模板已同步更新。

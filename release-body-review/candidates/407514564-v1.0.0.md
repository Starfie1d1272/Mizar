Mizar 首个正式版本，面向校园与社区 CS2 赛事。

### 新增功能

- 提供从赛前等待、BP、对阵开场到局内、半场、单图及整场结果的节目流程，可自动推进或人工接管。
- 制播工作台集中显示 CS2、大雷达、比赛资料、制作提示和 OBS 状态。
- 提供 Mizar Pulse、EWC、IEM、Perfect World、ESL 五套 HUD，支持预览、组件设置、布局调整和预设分享。
- 支持本地管理赛事、队伍、名单和 BP；连接 RivalHub 后可读取比赛资料并提供网站实时画面与雷达。
- 提供配置备份、连接恢复、未保存草稿保护和诊断导出。

### 升级提醒

- 支持 Windows x64、CS2 和 OBS。安装版资料保存在 `%LOCALAPPDATA%/Mizar`，便携版保存在 `state/`；从便携版迁移前请备份。
- 本版通过手动安装新版更新。整场结果的选手表使用最后一图数据。

### 使用范围
Mizar 1.0 支持 Windows x64 的 CS2 观战与 OBS 制作。节目编排负责场景推进，观察视角和推流启停由制作人员操作。半场与结果页使用单图统计，整场结果的选手表展示最后一图。

C4 伤害预测按当前位置与站立姿态估算，供观察参考；实际伤害以游戏结果为准。OBS 缩略图用于定期确认画面，开播状态用于核对直播连接，观众端音画需结合实际直播间检查。完整说明见[数据源能力](https://github.com/Starfie1d1272/Mizar/blob/e46dcf7ff5bf01703da2ee40491f503d1fc4d76b/docs/guide/data-source-capabilities.md)。

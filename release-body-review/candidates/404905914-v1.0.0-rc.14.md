### 新增功能

- 在准备中心“设置 → 游戏数据 → Steam 头像”可配置 Steam Web API Key 获取并缓存头像，官方申请引导建议域名填 `localhost`，无需购买域名；不填写也可使用 HUD。

- 无关联比赛的 Demo 使用中立身份；雷达地图与烟火范围按相同比例缩放。

- 修复单图结果页空白、选手统计遗漏，以及刷新比赛资料后结果摘要丢失的问题。

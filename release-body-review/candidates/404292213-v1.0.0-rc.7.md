### 新增功能

- Demo 有有效游戏数据时可手动切换到局内画面。
- 提供隐藏和恢复游戏原生 HUD 的可复制命令。

### 体验改进

- 单图结束后，五套 HUD 显示约三秒 GG 过渡，再进入结果页。

### 问题修复

- 修复 Windows 显示缩放下的窗口布局恢复问题。

### 升级提醒

- 复制 HUD 命令后，需在 CS2 开发者控制台粘贴执行。
